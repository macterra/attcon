# Attention-content model v1 design record

2026-10-11. Prospective design only; no run, checkpoint inspection, world generation,
training, inference, Reporter use, result or semantic qualification.

The exact proposed source contract is
[ATTENTION_CONTENT_MODEL_V1_DESIGN.md](../../../docs/ATTENTION_CONTENT_MODEL_V1_DESIGN.md).
That document owns the architecture, timing, unknown command mappings, fixed
development envelope, equal-information rivals, causal controls, denominators,
interpretation and subsequent-reporting dependency. This record is a concise
index, not a competing executable contract.

The bridge is a 197,328-parameter per-address GRU/residual-map predictor. It learns
current and prospective 24×4×4 maps from immutable V, command histories and
delayed completed feedback, while a native Controller selects a command using
the predicted frozen-H role field and then targets the executed W. The proposed
envelope is 96 fit/96 dev/96 heldout worlds per encoder, three existing frozen
encoders, fifteen transitions per world, one fixed 300-update fit. Unknown mappings
are independent per address. Donor-history states provide a declared reachable
local intervention without altering recipient V or W.

The ordinary predictor shares architecture, inputs, budget and Controller use;
the analytic alternative infers mappings from exactly the same observations.
Their parity is a legitimate explanation. The current native task gates are
unchanged; passing task utility does not qualify presentation manner. Failed
manner retains the negative semantic endpoint, with no guarantee that the new
architecture will support independently recognizable consciousness-report form.
Modeler refinement remains a separately registered stronger extension.

Independent design review and registration are outstanding. No next run is
authorized by this record, and no Git changes or publication were attempted in
this drafting subtask.
