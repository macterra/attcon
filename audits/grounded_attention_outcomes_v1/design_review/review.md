## Disposition

below.** No unresolved input leak, target-construction error or protocol/code

prospective attempt, not its as-yet-unobserved outcome. It does not approve an

## Input and target boundaries

The frozen sensor receives delivered RGB pixels only and returns hidden features
and raw orientation logits. Its failed probability calibrators are not consumed.
The collector stores latest-glimpse evidence by observed location and the most
recent observed delivery for **each** command row. Inference accepts only those
memory/history tensors. Evaluator labels, contrast, masks, phases, true mappings,
correctness and future decoded images are separate archived values.

Current correctness compares the actual stored decision with the evaluator's
orientation. Refresh correctness is measured on actual fresh rendered glimpses,
then scattered from command order into delivered-location order. Post-command
labels retain current decisions at every other location and replace only the
actually delivered location. Independent branch noise supplies two development
repetitions or eight evaluation repetitions; it does not create additional
independent worlds. No paired counterfactual orientation is used for sensing or
prediction. Static memory does not acquire artificial decay.

World/model/split seed ranges, including the nuisance and orientation offsets,
are disjoint. History, future branch, remap, fit and bootstrap generators have
separate fixed schedules. All 24 mapping permutations remain part of the same
development/evaluation family; an unseen mapping-class claim would be unsupported.

## Models and statistical qualification

The structured model learns route and current/refresh success from actual
outcomes. Calibrated source probabilities precede its exact static-update
composition. The joint comparator has a separate directly learned/calibrated
after head, and no gate demands structured superiority. Parameter counts and
training differences are disclosed. The history ablation retains observed-location
status; it is not the absence of all memory information. Masking occurs before
development-only normalization.

Calibration uses a disjoint split, fixed temperatures and signed-logit fits.
Success scores average actual Bernoulli squared errors; scoring a fractional
branch mean as a single deterministic observation would understate uncertainty,
and the assessment avoids that error. Constants use calibration labels only.
Known/unknown command status and seen/unseen query status are observable gates.
Delivery calibration is checked in each command/location cell rather than
concealed by a flattened aggregate. Latent contrast/orientation curves are
computed only by an evaluator after prediction and do not qualify the model.

Whole worlds are the split and resampling units. Paired Brier differences and
Controller gains have whole-world intervals. ECE, signed-residual and route
accuracy gates use point estimates, not population confidence guarantees. Empty
required strata fail. The small fixed bootstrap count gives approximate
engineering intervals; three frozen visual checkpoints are not evidence of broad
architectural replication or a powered consciousness endpoint.

## Controller and intervention interpretation

The Controller's query selection uses observed status, not correctness, scores
or future outcomes. Every evaluation world remains archived and analyzed, with
the unseen-query subset fixed by that rule before action evaluation. Choosing a
command from pre-command forecasts is compared against real withheld branch
outcomes and the uniform policy's expectation on those same branches. Ties and
zero-contrast worlds remain in these outcome contrasts.

Command-row rotation preserves physical mapping, sensory memory and history.
Unique-winner rotation is a consumption identity; actual loss of success under
corruption supplies the functional consequence. Neither implies an appearance
change. A known command already delivered to a seen location, so unseen-query /
known-command is a no-refresh control; useful exploration comes from remaining
unknown commands and permutation exclusion.

Physical remap updates observations and forecasts without updating weights.
Intermediate mixed old/new route rows are outside static-world training and are
retained. Final route accuracy tests revision from newly observed mappings.
Restoration in this protocol is exact restoration of saved **model inputs and
predictions**; it does not re-execute a restored physical world trajectory. This
is not an online-learning or general consistency-comparator demonstration.

## Corrections made before outputs

The preliminary review requested delivery probability qualification in addition
to top-1, explicit structured-versus-joint calibration semantics, preservation of
all command rows, world-level dependency handling, honest remap scope and
out-of-distribution disclosure. The final sources implement or document these.
During source development the runner/helper Controller signatures differed; they
now agree on an explicit model-kind argument. Nonprimary comparators now have a
null qualification verdict instead of passing by an empty gate dictionary.
Protocol wording now specifies sixteen delivery cells, point-estimate
calibration gates and 256 whole-world resamples. Evaluator-only contrast/label
diagnostics were added before freeze, addressing the risk of hiding previous
conditional calibration problems behind pooled scores.
