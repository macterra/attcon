# Grounded attention/acquisition bridge: design proposal v1

**Unfrozen, not executed, and not a theory-facing result.** This is a separate-context AI design review commissioned by the project. It reads architecture and existing documentation but does not load checkpoints, run inference, inspect new adapter outputs, or certify success. The task is to propose a bridge learned from executed sensory outcomes while preserving the full attention-model/qualia hypothesis. Shared model training and commissioning limit reviewer independence.

## Recommendation

Replace handassigned glimpse quality and deterministic probability decay with a small sensory world in which commands cause actual image delivery, a fixed sensory readout makes fallible orientation decisions, and memory stores observed evidence. Train the attention-control model to predict delivery and subsequent task correctness from its permitted history. Those are distinguishable predictions. A probability of .5 correctness on a binary task is chance performance, not a measured probability of acquiring information; neither predicted correctness nor sensory decision confidence is clarity.

The new all-contrast adapter and its calibration must qualify independently before this bridge uses them. The failed highest-contrast fit remains archived. Do not adopt this review's suggestions after looking at held-out bridge outcomes without documenting a new development attempt.

## Minimal physical task and event definitions

Use four locations containing independently generated horizontal/vertical synthetic gratings. Each episode fixes label, aperture, geometry and contrast for each object; every delivered glimpse gets independent sensor noise. A command requests one location. The first environment has a fixed unknown permutation mapping commands to actual delivered locations; a replay channel or command-independent schedule supplies an explicit external/decoupled control. Balanced mappings and random exploration make contingencies learnable without condition labels. The environment records requested command, actual delivered location, actual image, decoded orientation, and task outcome. Image delivery is an observable discrete event. Correctness is computed by the evaluator by comparing an emitted answer with the hidden world label.

Start with latest-glimpse memory and static labels. An unseen location has no stored observation, a neutral binary content distribution and a fixed declared guess rule. A refresh replaces that location's stored sensory evidence with the newly delivered evidence. No artificial q multiplier, accuracy label, world label or appearance judgment enters content memory. A static stored choice stays just as correct as it was initially; elapsed time alone must not create .75 decay. Age is still recorded because it can matter in later, separately specified dynamic worlds.

Do not promise that refreshing an already accurate static memory improves performance: new noise can worsen it. The minimal useful control task targets unseen or initially weakly represented locations. A subsequent evidence-accumulation or changing-world extension requires its own frozen integration rule or learned memory decoder and fresh qualification. Changes must be physical, not a handassigned loss of access. Latest-glimpse and evidence-accumulation systems have different counterfactuals.

The high-contrast benchmark does not cover all operating conditions. The sensory adapter must supply useful behavior at the explicitly declared positive contrasts and honest chance behavior at zero; the controller qualification should include difficult conditions rather than select only easy trials. A zero-contrast refresh supplies a new image, but cannot systematically improve orientation accuracy. This is a negative control, not evidence of absent consciousness.

## Inputs, labels and learning boundary

The world-content subsystem receives delivered image features and produces orientation evidence through the independently frozen adapter. Memory retains object-addressed evidence, last delivered location and observation time. The attention-control model receives command history, observed delivery locations, observed sensory evidence/available uncertainty features, and memory/update events. A GRU may summarize this history, but a feedforward learned predictor with the same sufficient history is an essential comparator. No hidden world orientation, simulator control-owner flag, human confidence/visibility, physical contrast label or calculated target success probability is supplied as model input.

Observed feedback is optional: choose one explicit policy before collection. The simplest initial design keeps correctness feedback out of inference entirely. Supervised training targets can use recorded correctness, just as supervised visual learning can use labels; reserve all evaluation labels to the evaluator. If online feedback is later included, expose only feedback actually delivered on queried trials and include a matched no-feedback comparison. Do not insert the evaluator's correct/error label into every historical object entry.

Train on randomized executed actions, not exclusively on the model's current policy. Save training, calibration and evaluation episode identities, mappings and image-noise seeds separately. Hold out full episodes, worlds and relevant mappings; all images and branches from one world remain within its split. Never mix branch images across fit/calibration/evaluation.

The model predicts (a) next delivered location for each command, (b) probability the system's current stored answer at each location is correct, and (c) probability a declared post-command sensory-and-memory decision is correct for each command and queried location. Optional delays need explicit physical transitions. Allocation/delivery heads learn categorical events; task-success heads learn binary executed outcomes. Targets are realized event/correctness labels or averages of separately executed branches, not the old q recurrence or the adapter's own confidence. The latter may be an input/comparator, not ground truth.

## Command counterfactual ground truth

At each reserved evaluation history, clone the physical world and content-memory state before action. Execute each command through the environment; deliver a newly rendered image using independently sampled noise; update memory by the fixed rule; and emit the same fixed orientation-answer rule. Archive both actual delivery and correct/error for every branch. Repeated branches estimate each command's success rate and its Monte Carlo uncertainty; branch count and noise schedule must be fixed before outcomes. Common random numbers can improve paired comparisons but must not cancel noise by feeding two alternative images to the decision instrument.

Train either on actual randomized single-action outcomes, or on a separately declared development set of executed counterfactual branches. In both cases reserve evaluation branches fully. The model cannot see branch images, hidden labels or post-command sensory margins when making the pre-command forecast. Comparing an observed post-command margin with a future forecast would leak the outcome. Compute Brier/log loss on individual realized outcomes; report reliability by contrast, memory state and mapping/control condition, with world-level uncertainty. A finite branch mean is not an exact oracle probability.

## Bound representation and separate roles

The world representation retains sensory orientation evidence and memory content. The attention-control model represents action-to-delivery contingencies and predicted task success. Bind them by actual location/object address, retaining both components and their provenance. Do not multiply content by predicted correctness to manufacture an appearance intensity or flatten orientation evidence into a score named clarity. A relational record can say which represented orientation is associated with which modeled delivery/action relation; it need not invent a new scalar phenomenal head.

The Controller chooses commands to improve a declared queried task outcome, for example maximizing predicted post-command probability of correct orientation at an unseen queried location. It then executes the chosen command in the independent world. The Reporter reads a neutral, versioned view of represented content, predicted relations and genuinely observed events. It never chooses commands and is not identified as the experiencing subsystem. Factual reporting describes model estimates as estimates; outcome feedback and evaluator truth remain distinct.

Success of the decision-confidence calibrator alone does not qualify an attention model. It lacks action contingency, allocation histories and consequences. Conversely, command-conditional forecasts that generalize to mappings and revise after executed evidence establish a functional attention/acquisition model even if an information-matched feedforward model predicts as well. A dedicated recurrent module or architectural label is insufficient.

## Selective intervention, restoration and source controls

First change a represented command mapping/effect table while preserving world images, memory content, preintervention history and physical mapping. Controller commands should follow altered modeled consequences; resulting decisions should be judged by actual physical outcomes. Restore the exact saved state and replay fixed noise to verify restoration. Report altered forecasts faithfully, not as newly established physical facts. Next change the physical mapping while initially holding the model fixed; show subsequent observed deliveries revise the model. Immediate forecast error is an appropriate response to this cross, not a failure the reporter should hide.

Separately permute binding addresses while preserving the marginal set of content distributions and the marginal set of attention predictions. Evaluate whether object-addressed decisions change. This is binding-specific causal instrumentation; a controller written to consume bindings will change by construction, so the intervention alone does not establish representational integration or qualia. Preserve unbound address-aware, visual-only, sensory-confidence-only, allocation-history-only and matched learned joint-predictor controls. Give each declared information boundary honestly and avoid handicapping a comparator by withholding needed addresses.

For appearance-source localization later, compare upstream sensory hidden state, stored world-content state, attention forecast/hidden state and bound joint state using identical held-out targets and matched probe budgets. A strong upstream appearance predictor limits attention-source specificity; it is not a failed prerequisite that should be excluded. Counterfactual forecast interventions must be complemented by naturally reached state changes and physical interventions, because arbitrary swapped values can be off-distribution. External/decoupled wiring controls also contain an attention model; their comparison is not automatically a theoretical necessity implied by the source-of-qualia claim.

## Qualification before any appearance interpretation

Freeze thresholds, branch count, episode count, model seeds, split rules, uncertainty calculation and stopping rule before collection. Recommended qualification requirements are:

1. Independent sensory task/calibration qualification across all declared operating contrasts, with retained failed attempts and negative controls.
2. Delivery/effect prediction substantially better than chance/permutation-invariant baselines on held-out mappings or explicitly stated mapping-learning episodes. Preserved decoupled invariance and successful adaptation after a physical mapping change.
3. Task-success predictions improve proper scoring over calibration-derived constant and sensory-confidence/history baselines where the action/history supplies information. Report conditional calibration, not only pooled ECE; do not require superiority over an equally informed joint predictor merely because it lacks the attention name.
4. Executed Controller choices improve correct-answer outcomes over random requests on the declared controllable task subset, with paired world-level intervals and all difficult/control conditions retained. Effects follow represented intervention, physical intervention and restoration in their distinct expected ways.
5. No leakage of evaluation labels/branches, condition IDs, human appearance targets or evaluator ground truth. Binding and raw sensory inputs preserved under interventions as specified. Memory semantics and noise sampling verified directly.
6. Fresh separate-context audit independently reconstructs outcomes and flags disagreements, source leakage, conditional failures and unsupported interpretations. Preserve code/data hashes and first passes.

These are engineering qualification requirements, not yet numeric frozen gates. Accuracy or calibration cannot certify appearance correspondence. After qualification, the full goal still requires an independently grounded appearance/report endpoint, attention/sensory manipulations that dissociate appearance from answer confidence, selective model intervention/restoration with source controls, factual reporting audit, powered confirmation and replication. A bridge learned from synthetic sensory outcomes supplies a credible causal substrate to test; it does not itself provide evidence that this substrate generates qualia.
