# Addendum: independent margin calibration is not a necessary dependency

**Unfrozen prospective design amendment, not executed.** The original review and metadata remain unchanged. This addendum responds to the parent's newly supplied terminal sensory-adapter result: the all-condition classifier produces useful orientation decisions, but the absolute-logit two-parameter correctness calibrator fails the registered conditional calibration gates for every model. The reviewer has read the frozen protocol and pre-output design review; it has not loaded checkpoints, run inference, inspected the new numerical outcome archive, tuned a new model or independently verified the parent-supplied numbers.

## Verdict and correction

A separately calibrated sensory-margin probability is **not logically required** for an attention/acquisition model that consumes no such probability and learns its own event/outcome predictions directly from executed sensory decisions. My first proposal imposed an unnecessarily strong dependency by demanding sensory correctness calibration before any bridge, rather than asking whether that intermediate probability is actually used. This correction is explicit and prospective. It does not repair or reinterpret the failed frozen sensory-adapter attempt.

The frozen protocol states that a pass permits bridge design and that failure leaves acquisition grounding incomplete. The present proposal does not claim that pass occurred, waive that gate, promote the failed calibrator or establish grounding. It proposes a new study whose input and learning boundaries remove the failed intermediate instrument. Preserve the frozen FAIL, its conditional errors, all sources and all three checkpoints. Record this amendment as development informed by the predecessor failure, not as a preplanned success of the predecessor.

## What can be reused and what cannot

The frozen orientation decision function can be reused as a explicitly identified task component: it emits a hard horizontal/vertical answer according to its unchanged raw-logit rule. The component's previously registered highest-contrast and null accuracy checks are narrower facts than the overall study verdict. No lowest-positive accuracy gate should be invented retrospectively, and good observed low-contrast accuracy does not qualify its probability outputs or future deployment distribution. The new bridge must independently retain and measure decision performance across its actual sensory/history conditions.

Permissible pre-command inputs include delivered sensory hidden features, the fixed task's **raw signed logit**, observed delivered location, past commands, memory state and observation timing. These are factual instrument states, not guaranteed orientation posteriors or probabilities of correct answers. Training-only normalization is permitted if frozen before evaluation. Neither sigmoid(logit) nor the failed fitted correctness probability should be described as calibrated. The failed absolute-logit correctness map should be wholly absent from the new input, target, content-memory update, controller utility and reporter interface; leave it only in an explicitly labelled descriptive legacy comparator if needed.

No human appearance/visibility/confidence target, evaluator world label, physical contrast label, future branch image, post-command score, control-owner label or evaluation correctness should enter the pre-command predictor. The trainer/evaluator may use known synthetic orientation to calculate realized correct/error supervision; this is target supervision, not permission to give hidden labels to the model at inference.

## Direct outcome learning and remaining calibration requirement

The new model may train a binary next-delivery head and command-conditioned correctness heads directly on executed outcomes. A probability head fitted by binary loss is an estimate; calibration remains an empirical obligation. The bridge must qualify its **own** current and post-command forecasts by contrast, memory state, queried location, mapping/control regime and other prespecified relevant conditions on fresh held-out worlds. Keep proper scoring, conditional residuals, reliability bins and episode/world-level uncertainty. Do not substitute pooled ECE for conditional qualification again.

A separate sensory calibrator would become necessary only if the architecture consumes its value as a probability in a probabilistic update, treats it as a target probability/q for attention training, or uses an analytically composed forecast/controller whose validity requires that sensory probability to be calibrated. In that architecture, downstream reliability depends on the failed component and must not be assumed. The proposed direct-outcome path avoids this premise; it does not avoid downstream forecast qualification. Hard task answers can be assessed by correctness without assigning them confidence probabilities at all.

Train on randomized executed actions and define the fixed content-memory update before outputs. For cloned counterfactual evaluation, execute the actual command, render independently noisy sensory input, apply the frozen task and memory rule, then calculate correctness. All forecast inputs precede this branch. At static labels, stored-answer correctness remains stable with age unless a specified physical/memory process changes it; do not reinstate q decay. Chance correctness, delivered-image events and incremental benefit of refresh remain distinct quantities.

## Attention role and non-tautological comparisons

A neural decoder of current sensory correctness is a task-confidence instrument. Calling it an attention-control model does not make it one. The new bridge earns the functional description only if it learns observable command-to-delivery contingencies and predicts consequences for the system's object-addressed content decisions, supports appropriate executed choices, revises after new contingency evidence and exhibits the declared selective intervention/restoration behavior. Delivery labels and task-correctness labels should remain separately identifiable.

Even those demonstrations qualify a functional architecture, not qualia. The bound representation must preserve location/object address, sensory evidence and modeled action consequences as distinct components. Do not turn predicted correctness into an appearance intensity, redistribute it into an orientation posterior by definition, or award a phenomenological result because a controller consumes the new forecast.

The new model receives richer features than the failed two-parameter calibrator. A calibration improvement over that weak predecessor would therefore not establish an attention contribution. Include a sensory-only correctness predictor with the same sensory hidden/logit information and matched learning budget; a history/memory predictor; and a joint predictor with the same full information, parameter/readout budget and training supervision. Width equality alone does not equate parameter count. For intervention/source localization, compare upstream sensory state, world-content memory, action/history state and bound state on identical held-out target rows and probe budgets. Archive information boundaries and parameter counts.

A stateful action predictor can improve future-outcome forecasts beyond instantaneous sensory evidence without being superior to a fully informed joint comparator. Such parity does not invalidate the functional model. It limits claims that the chosen attention module is a uniquely informative or necessary source. Attention-specific interpretation needs selective causal changes with preserved sensory inputs, memory contents and matched alternatives, and ultimately independently grounded appearance correspondence. Decoder accuracy alone cannot supply that interpretation.

## Guard against moving the goalposts

This revision is justified by an input-boundary argument that holds irrespective of whether the next study passes: no learned probability calibrator is necessary for a task that uses hard decisions and trains a new predictor on actual outcomes. It becomes outcome hunting if the project suppresses the old FAIL, relabels passing submetrics as overall success, loosens the new conditional gates after seeing outputs, changes memory/counterfactual semantics to obtain desired effects, selects favorable checkpoints, or claims appearance/qualia from the resulting forecast calibration.

Before collection, freeze the new source manifest, exact retained/rejected predecessor components, data splits, model budgets, conditional gates, counterfactual branch execution, comparison sources, sample/seed counts, interventions, stopping rule and evidence hierarchy. All three original visual checkpoints and failed legacy predictions remain visible; use fresh reserved episode/evaluation draws. Record development knowledge of predecessor outcomes and separate the next design review from post-output auditing. If the new bridge fails, retain it without retroactive repair.

A new bridge that passes these engineering qualifications would remove a synthetic outcome-grounding gap. It would still leave native/reference transfer, independent appearance targets, attention/sensory dissociation, selective model intervention/restoration, diagnostic-report correspondence, powered confirmation and replication incomplete. The full attention-control-model-as-source-of-qualia goal remains unchanged and unachieved.
