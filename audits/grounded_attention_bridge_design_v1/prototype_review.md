# Static review of unqualified grounded-world primitives

**Scope: static prototype review, not execution or architecture qualification.** Reviewed `scripts/grounded_attention_world_v1.py`, `tests/test_grounded_attention_world.py`, and the imported renderer/nuisance construction in `scripts/isolated_orientation_task_v1.py`. No checkpoint loading, inference, numerical outcome-archive inspection or tests were performed by this reviewer. The parent's four passing fixtures are reported commissioning context, not independently reproduced here. The original design proposal and subsequent calibration-dependency amendment remain unchanged.

## Findings that match the proposed boundary

- World orientations are drawn by `torch.randint(2,(4,))` using a separate label generator; they are not forced to two horizontal/two vertical within a world. The balanced labels produced by the nuisance helper are discarded. This avoids inferring one location's hidden orientation from assumed world balance. Geometry, phase and contrast are not fed into `model_input()` as labels.
- `execute()` resolves the command through the physical mapping, renders that location's image, calls the sensor on the image, advances time and updates only the delivered location. The observed record contains command, actual delivered location, raw sensory logit and time. No world orientation, correctness, contrast or condition flag is exported in that record.
- Latest-glimpse memory retains raw logit, observed mask and last-update time. `advance()` clones evidence unchanged. Unseen/tie answers are deterministically horizontal. There is no invented accuracy/access decay or probability multiplier.
- `evaluator_correctness()` compares the fixed sign decision with hidden world labels separately. This is legitimate evaluator/training-target computation, not an observed input. Its availability in Python does not authorize passing it to the model.
- Each counterfactual starts from the same pre-command memory. `execute()` clones memory and renders a cloned image; implemented branch updates do not write into the starting world or memory. Caller-supplied per-branch noise and the same deterministic sensor permit replay. The helper never constructs a forecast input from post-command branch information.
- Remapping preserves labels and sensory nuisance state, so it can support a physical action-mapping intervention without changing the queried image. The fixture uses constant toy callbacks and evaluator labels to construct a deliberate worsening test. Such test-only callbacks are not trained sensors or scientific evidence.

## Corrections/clarifications before saving this as a reviewed prototype

1. `represented_content()` currently converts raw logit to `(1-sigmoid(logit), sigmoid(logit))`. These normalized coordinates are **uncalibrated transformed task scores**, not established orientation posteriors, calibrated distributions, correctness probabilities or appearance intensity. The code should explicitly label that status, or expose raw signed evidence instead. This is particularly necessary after the calibration failure and the amendment's decision to exclude probability assumptions. Normalization alone is not calibration. Its use in later probabilistic memory updates would require a separately justified/qualified model.
2. Document that frozen dataclasses prevent attribute reassignment but their tensor contents remain mutable. The present functions clone on transitions; they do not enforce immutability for arbitrary callers. Future intervention/replay auditing must check source tensors before/after operations rather than rely on the Python decorator.
3. `counterfactual_branches()` consumes caller-provided noise; it does not generate or guarantee independent noise. The study driver must freeze and archive the fresh-noise generator/schedule and forbid paired-image noise cancellation. Repeated identical noise is allowed for replay, not evidence of independent branch sampling.
4. The arbitrary sensor callback can close over hidden labels or state. A future run must bind a frozen, audited image-only adapter implementation with source/checkpoint hashes and no world/evaluator captures. The test callbacks do not establish that production boundary. Keep evaluator-only branch targets away from generic serialization/model-input construction.

These clarifications do not require a new numerical outcome or architecture pass. The code can be saved as unqualified development primitives once its evidence-coordinate semantics are explicit; it should not be described as an implemented/qualified attention model.

## Remaining unimplemented requirements

There is no learned attention predictor, training split, calibrated outcome forecast, Controller, Reporter, source comparison, external/decoupled replay condition, independent counterfactual noise generator or frozen study gate in this prototype. Current observation records contain only the raw task logit, not retained sensory hidden features; any later richer-input architecture requires an explicit versioned input boundary and matched source controls. Empty-memory probability semantics, if any, remain an arbitrary neutral representation plus a fixed guess, not a measured absence of content/experience.

The fixtures guard selected invariants but cannot demonstrate conditional calibration, learned action contingencies, adaptation, executed Controller uplift, mapping holdout, participant/reference transfer, appearance correspondence or attention-source causation. Preserve this distinction in milestone/docs language. This prototype is useful preparation toward outcome-grounding; the full qualia-source objective remains unachieved.
