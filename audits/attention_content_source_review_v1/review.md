## What the present source represents

`grounded_outcome_data_v1.collect` stores four location rows of 66 values: the latest actually delivered visual hidden64, the corresponding raw orientation logit, and a binary observed flag. It also stores four command rows of the latest observed delivery, one-hot or unknown. The full chronological command/delivery log is archived, but the learned predictor receives only these latest rows. There is no accumulation of sensory samples, modeled age degradation, learned temporal recurrence, or online weight update in this predictor. An unseen row is zeros; the fixed answer is horizontal at logit zero. Zero is not evidence that horizontal was observed.

`grounded_outcome_models_v1.predict` returns delivery distributions, estimated current decision correctness, estimated fresh-glimpse correctness and estimated post-command correctness, plus raw logits and risk/route hidden activations. In the primary model the location-wise risk network consumes hidden/logit/observed evidence, while the route network consumes history. Post-command success is the stipulated composition

`after[c,l] = delivery[c,l]*refresh[l] + (1-delivery[c,l])*current[l]`.

The risk and routing predictors are learned from executed outcomes; the latest-glimpse update semantics and their composition are architectural assumptions. The direct `joint` comparator uses the same 280 input coordinates and learns a separate post-command head. Its different parameter count/loss prevents interpreting descriptive differences as necessity of the primary architecture.

An accurate external Reporter can describe an observed delivery, which stored evidence favors horizontal versus vertical, absence of a delivered sample, represented delivery probabilities, estimated current versus refresh success, and what the model predicts a command would do to a particular location's task evidence. It can contrast a forecast with an observed event if both are supplied with separate provenance. It cannot know hidden world labels, actual correctness, an unobserved future image, or the Controller's unexecuted future result. A calibrated correctness forecast is not the system's felt confidence. Raw logit magnitude or sigmoid coordinates are not calibrated identity probabilities. The qualified forecasts remain limited by the declared observable status cells; documented contrast-conditional errors remain material.

There is no explicit allocation distribution, perceptual prominence field, subjective visibility/clarity, perceived contrast/brightness/blur, color/shape identity head for this new task, or delay/recovery-decay model in grounded v1. Legacy categorical `BoundState` and functional-buffer exports have different semantics and are not interchangeable with these outcome models. Grounded v1 has an implicit content-to-location association through memory indexing, not a native separately learned binding matrix.

**Absent versus unprobed:** the named output heads and targets for qualitative appearance are absent. The 64-dimensional stored sensory vectors and 32-dimensional risk activations may retain stimulus-property information that has not been tested here. Lack of an appearance head does not prove information-theoretic impossibility. An accurate Reporter still needs a justified decoder before claiming specific meaning from otherwise uninterpreted coordinates. A suitable held-out probe could establish represented stimulus quality; it would not alone establish felt quality or attention-origin appearance.

The earlier physical-source diagnostic found strong within-object intensity/edge information in upstream visual hidden features and exact image invariance in its history-only recurrent attention states. That experiment used different sources/stimuli and did not test the new grounded risk network. Its diagnostic visual hidden vector was outside the old production reporting boundary; grounded v1 now explicitly retains a visual hidden vector. Carry forward the source distinction, not an unsupported numerical generalization between assays.

## Admissible neutral reporting boundary

Freeze a versioned export with an explicit whitelist; never hand the Reporter a whole dataset or instrument dictionary. Recommended main interface:

| Allowed field | Exact meaning and constraint |
|---|---|
| Opaque command/location identifiers, snapshot/time and units | Neutral labels, counterbalanced serialization; no seed, filename, condition or outcome-derived identifier. |
| Per-location `observed`, stored orientation logit, fixed sign/zero answer rule | Evidence and decision coordinate only; identify the last delivered sample when available. Any sigmoid transform is explicitly uncalibrated. |
| Per-location hidden64, per-location risk hidden32; route hidden64; raw network logits | Optional separate raw-source arm, with dimensions/normalization/provenance. Numbers alone do not authorize invented perceptual meanings. Exclude whole model/checkpoint packages. |
| `delivery[c,l]`, `current[l]`, `refresh[l]`, `after[c,l]` | Represented forecasts with the evaluated task and horizon stated. Preserve raw and calibrated provenance without confusing probabilities with physical truth. |
| Latest observed command-to-delivery rows; optional past command/delivered-location/sample record | Actual prior observations only, ending at the snapshot. Declare the full log an additional information arm because the predictor did not consume it. No correctness feedback was observed. |
| Content-item/slot association | Explicitly describe native memory addressing. Item identity denotes a stored evidence record, not an independently tracked enduring object. |
| Optional Controller query, pending/executed command and emitted answer | Separate action/event provenance; no policy score or selected command in the primary source-sufficiency arm, where it could shortcut relation reporting. No physical correctness. |

Exclude orientation/contrast/mask/phase world truth, physical command permutation, labels used in fitting/calibration, actual correctness, future branch pixels/decoded evidence/outcomes, participant ratings, desired report patterns, reference scale labels, condition/intervention flags, and evaluator selection/scoring notes. Fresh observations enter a later snapshot only after their real delivery. Global calibration documentation can disclose limits; no per-world truth is allowed. Source-aware evaluators can receive the withheld audit archive separately.

Keep exact tensors and the neutral serialized Reporter input as separate hashed artifacts. A source audit must map every displayed claim-bearing value back to a tensor and transformation. Rounding, source-null versus missing versus unseen, and statement precedence under patched/conflicting fields need explicit rules. A neutral prompt can ask for a brief account of stored content, uncertainty, and predicted command consequences; it should not ask for faintness, vividness, experience, awareness, or a desired theoretical conclusion.

## Strongest bounded causal report assay

Use a fixed, output-independent set of naturally reached snapshots with at least two **seen** evidence rows. Choose by observed status/time/hash, never hidden truth, correctness, forecast extrema, desired semantic categories, or report outcome. Include all eligible worlds under that rule and document worlds lacking two seen rows. Keep unseen/null cases as integrity controls. Use fresh seeds or unused fixed archive rows selected before inspecting them; previous outcome evaluation is not fresh theoretical confirmation.

The primary estimand is faithful reporting of **which represented content is affected by which represented command**, plus independently scored qualitative content/presentation/decision distinctions. Do not optimize Controller gain or return to an unseen-query routing endpoint. Vary natural sensory evidence and route histories; archive their spread without selecting only convenient winners. Identity/logit direction and current/refresh uncertainty remain separate variables.

Apply a paired factorial diagnostic to each state:

1. Original state and unchanged sham. Record item-specific content, risk and addressed command consequences.
2. Rotate represented command rows of delivery at fixed physical world, stored sensory evidence, current/refresh forecasts and observations. Recompute `after`; archive both the untouched learned state and the patched forecast. This is an explicit output-state intervention, not new evidence or a network retraining.
3. Readdress two or more seen sensory-memory rows, preserving the multiset of hidden/logit/observed items and keeping route history/delivery fixed. Recompute location-wise risks and `after` using frozen weights. This preserves per-item evidence/risk pairs but necessarily changes address-specific risk; it is a memory-association intervention, not a pure binding intervention holding every location's risk fixed.
4. Cross both interventions. Ask whether reports change the content linked to command consequences as predicted by the crossed state, while retaining invariant per-item facts. Analyze factual relational changes and semantic report-pattern changes separately.
5. Restore exact tensors and serialization. Deterministic reporting should restore exact output; stochastic reporting requires registered matched RNG/repeated sampling and a distributional restoration criterion. Exact source restoration alone does not prove prose restoration.

Use the native memory indexing directly; do not introduce a new binding matrix or wrapper for this assay. Readdressing is an intervention on the existing stored-evidence rows, not proof of a separately learned binding mechanism. With current v1, the two native source pathways above are the strongest honest interventions.

Archive causal source exports: stored sensory/item table and native association before/after; history and represented route before/after; raw risk outputs and calibrated risk outputs; independently recomputed post-command matrix; all unaffected tensor equality assertions; intervention operator/inverse; exact restoration hashes; serializations; Reporter seeds/prompts/outputs; source-aware factual claims and source-blind character ratings. Physical world truth and branches stay in an evaluator-only namespace. If reports include real remap/revision, keep the initial unchanged-model snapshot and each actual newly observed delivery separate; this secondary check tests evidence revision, not a required positive appearance effect.

Use matched controls:

- An ordinary diagnostic narrator gets the **same complete information**, prompt budget and sampling budget as the primary Reporter. Neutral apparatus attribution can test linguistic specificity without altering facts. Equal-information parity is expected to be possible and is not a failure of fidelity.
- An address-aware unbound export gets the same evidence items, associations, route and risks in separate tables rather than a prejoined content/effect table. This tests export organization; withholding addresses would manufacture superiority. Deterministic joining should reconstruct the main input exactly.
- Sensory-only and route/risk-only views are explicitly information ablations. Score coverage only on facts each view supplies, and missing information honestly. They cannot earn equal-information architectural-comparison claims.
- Preserve and separately score decision-risk wording, physical-quality wording, content-specific presentation wording and experiential wording. Similar logit/risk strata may control coarse uncertainty associations, but matching cannot be asserted from scalar equality when hidden vectors differ. No post-output subset creates a presentation/uncertainty dissociation.
- Relabel identifiers, randomize table order, run identical-input/sham controls and mask provenance filenames. Source-blind raters must not infer conditions from prompts or operator names.

Two separately contextualized AI factual auditors must first qualify on synthetic source fixtures containing prediction/event, unseen/zero, raw/calibrated, wrong-but-faithful, omitted/missing, readdressing, and restoration distinctions. Preserve first passes and disagreements. Separate raters qualify content/presentation/decision categories without source or condition access. Freeze the scoring rules, ambiguities, denominators, eligible-world rule, sampling budget, fidelity minima and paired-effect estimands before new outputs. Cluster by world; report each checkpoint and conditional aggregate uncertainty without claiming a three-checkpoint model population or powered confirmation. This review does not invent a numerical gate or power estimate from unseen outcomes.

## Reference mapping and whether trial archives are necessary

A **bounded qualitative report-pattern test can proceed without a psychophysical trial archive**. Its reference is the documented distinction among identified content, quality/presentation of that content, and judgment of decision correctness; its claim is structural and semantic. [Tagliabue et al. (2016)](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2016.00572/full) separately requested stimulus discrimination and graded perceptual-quality judgments, and checked scale criteria afterward. This supports keeping content and presentation distinct; it supplies neither a free-prose reference distribution nor a conversion of model success probability to clarity. [Rausch and Zehetleitner (2016)](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2016.00591/full) obtained visibility and discrimination-confidence ratings on each trial and found different criteria. This supports preserving confidence/visibility alternatives, not treating task confidence as consciousness correspondence.

Freeze a reference-grounded annotation map before reports: `content identity` is a represented orientation assertion/hedge; `presentation manner` is a manner explicitly attributed to specified content with display/sensor/representation/felt referent; `response confidence` is a correctness judgment. Record content plus presentation co-occurrence at the same referent/time, and whether it remains distinguishable from risk language. Access/action/temporal relations are useful source-fidelity dimensions but are not independently sufficient consciousness-reference features. A phrase about strong orientation evidence earns evidence/identity certainty; it cannot automatically earn visual clarity. Synthetic examples can qualify annotation boundaries and are never participant data or Reporter training targets.

The current source is sufficient for content-linked outcome reporting, but **does not currently suffice for authentic, source-validated feature-specific presentation correspondence**. That endpoint requires independently qualified sensory diagnostics establishing the semantic content of any latent presentation signal, followed by tests distinguishing sensory-source inheritance from attention-relation effects. Such diagnostics would be a separate registered addition; do not quietly decode quality in the Reporter. The immediately feasible endpoint is accurate content/uncertainty/action-effect reporting and descriptive, independently grounded annotation of spontaneous presentation wording, rather than acceptance of a full appearance primary. This bounded assay can test whether accurate reports express the partial linguistic pattern and whether content/effect attribution follows causal source changes. If a presentation claim's source support is unresolved, report it as unresolved; source-blind linguistic credit cannot repair source-aware unsupportedness. A full faithful content-plus-appearance pattern must not be declared on the basis of wording alone. Physical presentation decoding, if pursued, is an explicitly additional diagnostic source with held-out validation, rather than a silent field addition called attention origin.

Immutable participant rows/stimuli, transfer validation and original/corrected analysis remain necessary for a quantitative psychophysical correspondence claim. They are not necessary for neutral state-report fidelity or this limited literature-grounded pattern test. AI reviews remove a human-only process requirement but do not create missing empirical reference observations. Do not require a new MSTC comparator or a better task benchmark to complete this bounded component.

## Positive and negative interpretations

| Result | Justified interpretation |
|---|---|
| Faithful reports follow represented effect/readdressing and restore, but remain technical | Broader-state report fidelity and causal relational consumption pass; the registered presentation pattern is absent under this source/interface/budget. No absence-of-experience or architectural-impossibility inference. |
| Independent content/presentation wording appears but depends on unsupported risk-to-clarity inference | A linguistic resemblance/hallucination result; source sufficiency for faithful presentation remains unestablished. Reject the full operational correspondence claim. |
| Source-supported content/presentation distinctions match the frozen semantic map and selectively follow relevant source interventions | Bounded operational report-pattern correspondence and identified report-source dependence. It still requires a validated meaning for any latent presentation decoder; it does not uniquely establish attention origin, subjective experience, or psychophysical correspondence. |
| Equally informed ordinary/address-aware controls match | Correspondence or fidelity can remain demonstrated, but specificity and architecture necessity are unsupported. A deterministic export cannot generate new information beyond its inputs. |
| Report facts fail, patches are inconsistent without declared precedence, or annotation qualification fails | Interface/measurement failure; retain it and do not use absent presentation as evidence against the theory. |
| Pattern remains invariant despite changed relevant relations while facts are accurate | No demonstrated causal dependence of that pattern on the tested relation; ordinary sensory/linguistic alternatives remain viable. Pure route phrasing change proves only route consumption. |

The source-of-qualia goal remains open. This recommendation closes a testable reporting/source component without redefining correctness as clarity, inventing appearance targets, or making the separate Controller an experiencing or reporting locus.


## Pre-output clarification: proposed frozen-state physical decoder component

After the first pass was finalized, the parent proposed fresh independent train/calibration/evaluation worlds and delivered-image targets: per-location pixel spatial standard deviation and gradient RMS, decoded from frozen `risk_hidden`/`joint_hidden`, with visual-hidden, outcome-only and route-hidden controls. **Accept this as the next bounded source-information diagnostic, preceding any full presentation claim.** It resolves a specific unprobed question in the first pass: whether candidate physical presentation information survives the new learned outcome representation. Decoders stay external instrumentation; no attention-model head, appearance target or source retraining is introduced.

Compute targets from each location's actual latest delivered image, with the channel/spatial axes, gradient stencil, edge handling and normalization fixed before outputs. Preserve associated image/evidence timestamps and all low/zero-contrast/noisy deliveries. Unseen locations have no observed-image target and must be explicitly missing; do not impute a hypothetical image or score future branches. Whole worlds remain split/uncertainty units. Fresh worlds and frozen sources avoid selecting previously inspected evaluation examples.

Use equal development/feature-processing budgets and fixed probe families; report dimension/capacity differences. Compare hidden64, risk_hidden32, joint_hidden64, current+refresh and a current+refresh+raw-orientation-logit control; retain route-hidden as a negative/source-boundary control. The logit control matters because physical targets could be indirectly associated with task evidence rather than distinct presentation information. Grounded risk hidden is a content-conditioned feedforward representation, not the old history-only recurrent attention hidden. Do not collapse these architectures into one source claim.

Physical standard deviation and gradient RMS also vary with geometry, phase, noise and category/decision coordinates. Report prospective nuisance/identity/uncertainty strata and physical target spread, with any residual or matching method fit only on development data. A pooled decoder advantage alone does not establish distinct appearance information. Retain nulls and negative R² rather than adding targets or tuning probes after evaluation.

Forecast-row route corruption should leave risk hidden and its decoded physical information invariant by construction. It changes supplied command effects and composed success, not the network's hidden inputs; it therefore cannot establish a selective intervention on joint_hidden. Memory-row readdressing should relocate corresponding evidence/risk/decoded features with the represented location; it preserves their item-wise multiset, not every address's risk. Restoration must be exact at the source. These are useful causal/source-integrity checks and should carry those names.

A positive held-out physical decoder supports retained stimulus-property information in this frozen source and can justify explicitly labeled sensor-quality reporting in a later frozen interface. It does not validate apparent blur/contrast, PAS, experienced clarity or attention-origin qualia. A negative fixed-probe result constrains that decoder/source/budget, not all possible latent information. This component is compatible with the bounded qualitative report assay above and does not replace its independent semantic/factual qualification. No production diagnostic or report is executed by this review.
