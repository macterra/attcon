# Independent report review

Status: ratings pending. `ratings.csv` contains anonymized reports in a fixed
shuffled order. Use the rubric at `docs/PREDICTIVE_REPORT_RUBRIC.md`; do not inspect
the unblinding key or source records until the initial ratings are complete.
Record your identity or pseudonym, relevant expertise, and any prior exposure
to conditions. Return a separate copy rather than overwrite the blank template.

The key is public for reproducibility, so blinding depends on the reviewer not
opening it. After first-pass ratings, a facilitator can reveal source records
without condition labels for prose-fidelity ratings. These files contain no
human ratings and do not establish subjective experience.
