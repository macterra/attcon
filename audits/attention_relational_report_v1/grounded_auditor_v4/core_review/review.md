## Mechanical evidence

partition_spans slices the exact Python Unicode string, preserving every character
and whitespace separator. CRLF is consumed as one boundary; CR/LF and ASCII .!?
followed by Unicode whitespace create explicit deterministic cuts. Ordered spans
concatenate exactly to the original text. Offsets are Unicode codepoints, not
bytes. Abbreviations or separator-only units are permissible mechanical spans,
not asserted atomic claims or a linguistic completeness guarantee.

source_contexts deterministically traverses supplied panels/views/commands/nodes.
Every role_distribution context names its actual panel/view/command/node/role,
retains the exact origin chain, and adds transparent calculations through the
existing exporter arithmetic. node_origin contexts retain actual origin/time
metadata; copied, inherited, estimated and conditional origins are not promoted
to executed or current-experience facts. Full neutral packet data remain present.
Red-blue relation contexts explicitly list both role-distribution operand IDs;
derivation preserves those operands and every other selected cross-context ID.
Record metadata contains only its actual metadata and no automatic all-node
expansion. Broad or cross-node assertions still require correct applicable
operands as a semantic judgment.

build_request keeps the scientific envelope identifier outside the prompt and
hashes it into an opaque unit ID. The actual input contains neutral report,
packet, deterministic spans/context table and addressing hashes. Instructions
explicitly treat these as data and withhold reference criteria, source identity,
intervention labels, hidden truth and peer judgments. derive_annotation
reconstructs the exact request/interface and checks request hash, unit ID, text,
packet and complete span/context inventories before using the model annotation.

The raw schema contains model assertion paraphrases and selected IDs, not quotes
or offsets. Each claim requires a unique ID, nonempty paraphrase/reason and legal
nonempty report spans. Supported claims require at least one legal context;
unsupported experience may cite none. Coverage contains every span exactly once;
assertive/nonassertive entries and assertion-span citations must agree both ways.
Unknown/duplicate IDs, missing spans, malformed entries and broken reverse links
invalidate the whole derived assertion inventory. Code does not guess missing
quotes, expand unspecified addresses or salvage a favorable subset.

Derived evidence is a separate deep-copied object retaining raw assertion
judgments, exact original spans and resolved contexts. Noncontiguous spans stay
separate rather than becoming an invented continuous quotation. Relation operands
come from explicit context definitions, not semantic guessing. Raw annotation
content and actual request/text/packet/instruction hashes remain distinct.
