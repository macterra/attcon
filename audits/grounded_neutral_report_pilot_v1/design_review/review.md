The design preserves the actual source-of-qualia goal. Current strict presentation
counterpart qualification is absent; `Faithful_P_presentation` is explicitly
`not_established`, separately from linguistic P_presentation, P_access, A and scope.
It neither invents a native appearance property nor interprets correctness as
clarity. External physical estimates remain attributable objective readouts.
Reporter/Controller/source roles are separate. The strict continuation calls for
an independently justified counterpart and selective source dissociation, then a
fresh theory-facing experiment, powered confirmation and replication.

All 16 indexed worlds per three frozen models, snapshot8 and all four source
locations remain. Indexed queries use `location = world % 4`, `command =
(world // 4) % 4`, covering all 16 pairs per model without outcome selection.
The 13-arm/624-slot budget retains the native-memory × represented-route
factorial, sham, two source/prose restorations, ID remapping, same-information
ordinary-apparatus and exactly joinable-table controls, and three labelled
unmatched ablations. Adding the no-external arm isolates external readout access;
information-ablated inferiority is never called specificity evidence. Ordinary
comparator superiority is not a pass requirement or a new definition of the goal.

The source boundary retains only latest native observed-delivery rows, not audit
chronology/evaluator mapping truth. Current patched memory versus past history
precedence is explicit. Synthetic factorial states are separated from naturally
reached states. The combined arm is an export-only route-row patch on archived
moved memory/forecasts, with exact post-command recomposition. Original frozen
source bytes are not modified. All restoration and information-equivalence checks
must precede reports.

indexed location/command facts. The bounded main inventory has18 factual cells

all12 independent inventories/masks, exact complete class/scope evidence checks,
