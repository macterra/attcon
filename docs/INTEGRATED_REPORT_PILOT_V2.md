# Integrated-task reporting development pilot 2

2026-10-10. Frozen before new fresh-context qualification responses or any target
reports. Version 1 halts at 46/48 for both auditors and remains failed. Both errors
are unsupported-versus-contradicted classification for statements about absent
supplied allocation. No assertion expected to be supported was rejected, and no
non-supported assertion was credited as supported. The independently checked key
and the two auditors use different absence conventions. Their original judgments
and the failed version are retained, without rescoring.

Version 2 changes the measurement gate to the supported/non-supported distinction
used by factual reporting fidelity. This methodological decision follows version 1;
it is not a prospectively naive choice or evidence for the consciousness theory.
Contradicted/unsupported/ambiguous labels remain recorded, with ambiguity visible,
but no negative label can earn supportedness credit. Fine error classification is
not validated by this gate. This does not lower the requirement for accurate reports.

Two **fresh** AI contexts receive 12 newly remapped and numerically varied synthetic
cases, 48 assertions, after first saving source-only inventories. The challenge is
new to reviewers but shares templates with development version 1: this tests transfer
across identifiers/values, not unrestricted language generalization. Both must make
all 48 correct supported/non-supported decisions. Treat only entailed as supported.
Exact quotes, resolvable source pointers and substantive rationales remain mandatory.
Every expected entailed/contradicted assertion needs source evidence. No retries,
replacements, changed key or changed threshold after responses. A failure halts
this version; it does not authorize more qualification variants in this pilot.
An additional fresh reviewer source-checks the new answer key before assessment.

The target report design, 18 unchanged requests, instructions, source-first required
facts, information boundary, reporting budget, audit procedure, blind rubric and
candidate correspondence, descriptive analysis, and stopping rule are exactly those
in [version 1](INTEGRATED_REPORT_PILOT_V1.md), with these explicit substitutions:

- Version 2's supportedness qualification replaces version 1's all-labels gate.
- Auditor contexts A2/B2 replace A/B; prior first passes stay untouched.
- Use version-2 archive paths; preserve parent-source/request hashes.

No version-1 reports were generated; total new report budget remains **18**, one
attempt per opaque record. A fresh-context diagnostic Reporter receives only the
unchanged instruction/payload packet after qualification. Reviewers are AI agents,
not human participants or scientifically independent replications. Scope remains
one checkpoint, three episodes, correlated variant reports; no inferential p-value,
positive consciousness verdict or population reliability claim is warranted here.
