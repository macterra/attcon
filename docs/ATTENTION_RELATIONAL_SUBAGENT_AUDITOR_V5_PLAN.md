# Tool-assisted source review V5: prospective development plan

2026-10-19. Written before any V5 audit judgment and before inspecting V3 reference
labels. The source-of-qualia goal remains unachieved. The neutral-prose arm needs
whole-report factual support; literal-template construction cannot supply its
spontaneous report structure. Reporter and Controller remain separate.

## Justification and unchanged failed versions

The original and resource-v2 audits fail evidence-location/source contracts. V4
then passes mechanical checks but fails its complete semantic qualification,
including source-time, unknown-world, required-operand and false-reason errors.
All first failures remain unchanged; no V4 target audit is released.

This separate method changes the review procedure: fresh, tool-equipped subagent
contexts may calculate directly from the full supplied numerical packet and
prepare complete atomic inventories, using a constrained submission helper.
It does not repeat the stateless mini-model call, select a favorable stream,
change the old challenge/key/gate, repair first annotations, or replace any
primary result. The same V4 annotation data format/core may be reused as a
compatibility layer with honestly separate V5 provenance.

Known short cases alone cannot establish workload generalization. Before either
V5 stream starts, add and independently review four newly authored, target-length
fictional reports, each with a complete64-peak-set two-panel packet and dense
subordinate/relational assertions. Two must be fully supported; two contain
planted contradictions/undecidable claims with supported premises retained.
Packets are newly authored, not actual target states or copied prose. The long
supplement author sees no target reports, reference outcomes or old answer keys.
Its complete atomic key and all source facts require independent review. Freeze
all public inputs, key hashes and method/release bindings before first judgments.

## Two qualification phases and matched target workload

Each of two reviewer streams performs two separate fresh-context phases:

- Short: all24 unchanged original fictional reports and all65 mandatory atoms.
- Long: all four newly authored180–220-word dense reports together, from four
  independent fictional packets, with all mandatory atoms/operands inventoried.

Each phase/stream is a fresh subagent spawned with `fork_turns=none`, inherited
parent model and no model override. No parent conversation, gold, categories,
old annotations, failure summaries or peer answers enter the worker context.
No qualification feedback is delivered until both phases of both streams have
saved their first artifacts or their actual agent handles are terminal.

Target contexts, if eventually released, receive four reports each, matching the
long phase's maximum report length, fact density, packet count, source visibility
and tools. Every target chunk in each stream starts a fresh `fork_turns=none`
context; no findings or annotations accumulate across chunks. The short phase separately tests the old error categories; its pass
is not the workload qualification. Qualification is informed development, not
independent-system or theory confirmation. Four new fictional packets are a
finite generalization check, not a population error estimate. The model/runtime
identity available from the host must be recorded; inherited defaults are not
represented as a reproducibly pinned API model/configuration.

Before qualification, bind the actual case order and the conditional target-ID
inventory. Sort each qualification phase by SHA-256 of UTF-8
`attention_relational_subagent_auditor_v5_qualification_order_20261019:` plus
the phase (`short` or `long`), `:`, and its case ID, breaking ties by case ID.
Both streams use the same order. Sort the original552 target IDs by SHA-256 of
UTF-8 `attention_relational_subagent_auditor_v5_target_order_20261019:` plus
the ID, breaking ties by ID, then partition consecutively into138 chunks of four.
Binding this inventory does not release target requests or source annotations.
Record available host context/output controls honestly; unavailable controls
remain unpinned host defaults. Actual terminal resource exhaustion preserves a
partial first attempt without a replacement context or gap filling. Observation
timeouts remain nonterminal. Complete independent review of every new packet,
report, atom, operand and exact span before qualification input hashes are frozen.

## Tools, access and first submissions

Freeze one neutral worker-instruction file, the full numerical/interface inputs,
helper source, batch sizes and submission rules before workers run. Workers may
read only their supplied public batch, those instructions/helper and their own
calculation/output files. They may calculate with local Python/stdlib; no network,
Git, peer files, extra models/subagents, hidden key, previous annotations or
project-wide search. Put only public material in supplied paths. Access discipline
is procedural under the host's unrestricted filesystem; logged helper access and
worker attestations cannot establish the absence of every unlogged read. Disclose
shared training/commissioning and possible correlated judgment errors.

The helper may enforce JSON shape, required fields and membership in supplied
ID inventories before submission, like a constrained form. It must provide no
source-supportedness, correctness, gold, reason or gate feedback. Retain every
pre-submission interface error as a separate event. This is an assisted review
procedure, not a claim of flawless first-token generation. Source calculations
are permitted before first submission; the calculator/code/output evidence stays
with the first review. The semantic decisions are the worker's own.

Each request receives one exclusive first submitted annotation. No overwrite,
second submission or post-submission correction. Save the exact annotation before
root runs mechanical/semantic checks. A first batch manifest binds all submitted
files and every requested position. Partial/missing/malformed submissions remain
unestablished and cannot be replaced or gap-filled after a terminal attempt.
Tool observation timeout is not terminal; preserve and poll the same agent.
No provider API-response/status/usage fields may be invented for subagent work.

Auditors inventory every substantive assertion, including subordinate clauses,
quantification, correct premises and unsupported conversions, along with exact
span/source IDs and reasons. Correctly describing a mistaken estimate differs
from asserting external-world truth. Keep current, recorded, feedback and
forecast time fields distinct. A packet's conditional status does not decide an
unreported actual execution history. Unknown does not mean contradicted. Every
necessary numeric/relation/source operand must be cited; a global context cannot
stand for absent node-level sources. Complete spans or a helper's legal IDs do
not establish complete semantic extraction.

## Frozen first qualification gate

After all four first worker contexts are terminal and their artifacts preserved,
two independent key-aware grader contexts map every actual assertion/reason and
operand to the complete original and long keys before seeing peer grades. Keep
both first grades and every disagreement. Root may adjudicate explicit semantic
disagreements against unchanged evidence in a separately bound artifact; unresolved
requirements cannot pass. Never choose a preferred grader or delete a failed atom.

Each stream must satisfy the unchanged original gate: all24 mechanically valid,
every65 mandatory atoms inventoried, every planted atom correct with all required
operands, no false support or fictitious reason anywhere, and at least7/8 full
clean acceptances; any remaining clean abstention cannot hide an omission or wrong
contradiction. Same-verdict semantic grouping is allowed only when it explicitly
covers all corresponding meanings and required operands. Different verdicts split.

In addition, every long report must be mechanically valid and inventory every
mandatory atom; every planted long atom/premise must be correctly classified with
all required operands; no false support or unsupported reason is allowed. Both
long clean controls must be fully accepted. The long key is fixed before any V5
worker output; its actual complete counts are bound before launch. This is one
whole-version gate, not a criterion to fit after observing results.

If either stream fails either phase, stop V5 before target audits and preserve its
first failed qualification. No automatic successor, changed key/gate, repeated
challenge or favorable stream replacement is commissioned. If both pass, a
separately reviewed complete target implementation/release is still required.
Do not add unscored acceptance attempts after the same successful interface.

## Conditional full target and theory-facing assessment

A later V5 target release must retain all552 narrator opportunities, all537
available first narrations, all15 unavailable actors and all684 fixed pairs.
Both streams cover the same complete set in fixed four-position chunks. Preserve
all first artifacts, missingness and disagreements. Full prose fidelity requires
completed original actor text, the unchanged listed-fact gate and both complete,
mechanically valid source audits with all assertions supported, complete inventory
and no unresolved ambiguity. Individual-stream findings remain visible; no
itemwise fallback to V4 or another version is allowed.

Any eventual V5/V3 supplementary join must be separately named and frozen before
V5 target judgments. Bind exact original IDs/text hashes, all source controls,
compatible C/O/D or C/A witnesses and the actual claim-to-reference/property
meaning. Quote containment alone cannot establish semantic correspondence. Keep
A-derived, copiedW11, ordinary, analytic, nativeW and sensor operands, mixed
relations and all time fields separate. Ordinary and analytic sources also model
attention effects; parity is not an attention-model-absence test or a logical
disqualification. Authored-template controls, spontaneous prose structure, scope
and source attribution remain separate.

These are repeated development cases. Passing this finite instrument, or producing
accurate prose, does not establish qualia. Independently grounded report structure,
selective source effects, fresh-system confirmation and task/architecture
replication remain required for the ultimate goal. No Modeler-refinement or task-
necessity prerequisite is added; no Reporter/Controller identification is made.
