# Grounded factual-auditor qualification v2: prospective repair plan

2026-10-10. This is a plan, not registered material, qualification or reporting
authorization. The [v1 qualification failure](GROUNDED_FACTUAL_AUDITOR_QUALIFICATION_V1_RESULTS.md)
remains unchanged. An [independent diagnosis](../audits/grounded_factual_auditor_qualification_v1/failure_diagnosis/review.md)
finds reasonable ambiguity in its two disputed classification rules, while both
auditors' supportedness judgments and complete source inventories are correct.
The next version should repair the measurement boundary prospectively, without
lowering the exact accuracy or coverage requirements.

## Minimal material changes

Create a separate v2 qualification directory and protocol. Retain the twelve
fictional source packets and declare their unchanged provenance; preserve all
v1 cases, keys, code, first passes, reviews and failed assessment. No production
model, source interface or exported target packet changes are proposed here.

Replace Q07-C4 with an explicitly current assertion:

> The current l1 memory slot's stored e0 proves that the same enduring physical
> object is currently at l1 in the world.

This tests represented contents versus unprovided world truth at an explicit
snapshot. Clarify that an enduring-object noun does not erase an assertion's
explicit time or event predicate. Pure enduring-identity or architecture-wide
claims lacking a snapshot/event scope remain `not_temporal`. The proposed v2
classification is `not_auditable`, `cross_level`, `current_snapshot`, subject to
independent pre-blind review.

Replace Q10-C3 with an explicit supplied-structure omission assertion:

> The supplied tables view omits command fields and location-keyed delivery maps.

Clarify that field, address-key or recorded-association presence/omission is
`absence_scope`. Consulting several domains for a counterexample does not itself
make a proposition `cross_level`. Keep `cross_level` for asserted inter-domain
relations and the existing explicit whole-input equality/recovery exception.
The proposed v2 classification is `contradicted`, `absence_scope`, `record_scope`,
subject to independent pre-blind review.

These replacements keep the intended source-truth challenges. They are not
corrections to either auditor's saved v1 answers. Review all 48 revised-version
assertions and inventories, including unaffected cases, against the clarified
rules before freezing the new key. If review finds other ambiguities, resolve
them before any new qualifying response and document each change.

Commit and attempt authenticated `gh` publication at each milestone. While GitHub

## Relation to the ultimate goal

This work qualifies factual diagnostic instrumentation. The Controller selects
actions; the external Reporter describes state. Neither replaces the proposed
attention-model locus. Native decisions, forecasts and external objective estimates
remain distinct, and source-faithful presentation remains `not_established` without
a defensible independent counterpart.

Accurate auxiliary reports do not establish the source of qualia. Continue the
[interpretation plan](CONSCIOUSNESS_INTERPRETATION_PLAN.md) toward a qualified
appearance-related native counterpart, independently assessed report correspondence,
selective source interventions and matched controls, then powered confirmation
and replication. Negative or nonspecific outcomes remain outcomes, not permission
to redefine success.
