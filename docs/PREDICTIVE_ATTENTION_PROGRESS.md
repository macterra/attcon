## Retained pilot v1

Seed 811, 1200 updates, 512 fresh 16-step episodes (four-step burn-in):
allocation accuracy 100%; command-effect accuracy 99.957%; controllable-channel
accuracy 99.951%; access MAE 0.0238 (maximum error 0.3618). Reconstruction Brier
0.16946 versus simulator-probability oracle 0.16792. All 512 queried controlled
slots selected correctly; synthetic command-effect rotation changes all choices
and restoration is exact. These are development results, not confirmation.
