# Relational reporting: resource-amended measurement v2

## Purpose and registration timing

This is an additive measurement of the existing fixed report corpus, with more
output headroom for its factual auditor and source-blind reference rater. It is
not a new narrator collection, a new source experiment, or independent
replication. The original 8,192-token annotation batches remain the first
measurements and continue unchanged. Their incomplete and failed outcomes remain
unestablished measurements, not negative consciousness judgments.

This amendment is selected from provider completion, token-use and cap metadata,
before analyzing the original annotation labels or text. Its registration snapshot
records the exact observed metadata and first-outcome hashes. It also follows the
[single fictional, unscored resource check](../audits/attention_relational_report_v1/resource_acceptance/result.md),
which completed with 8,688 output tokens and passed the frozen JSON/quote-offset
validator. That fixture does not establish semantic rating accuracy, completion
on the study corpus, or any consciousness-related result.

## Fixed inventory and only resource changes

Use the byte-identical request and lineage files from
`run_v2/audit_preparation` and `run_v2/rate_preparation`. There are exactly 537
auditor requests for completed narrator responses and 1,104 blind-rating positions
(552 narrator positions and 552 literal-template controls). All 552 narrator
opportunities remain in the scientific denominator. The 15 incomplete narrator
responses are not regenerated or promoted; their empty-text rating positions and
unestablished factual status remain intact.

The model remains `gpt-5-mini-2025-08-07`, medium reasoning, low verbosity,
concurrency six per stage, zero SDK retries, fresh stateless requests and
`store=False`. Instructions, strict response schemas, reference pack, source
states, free prose, templates, opaque IDs, ordering, lineage, validators, endpoints
and interpretation rules remain identical. The only API resource changes are:

| Resource | Original first measurement | This supplementary version |
| --- | ---: | ---: |
| Maximum output tokens | 8,192 | 32,768 |
| Client timeout, seconds | 180 | 600 |

The new exclusive output roots are
`audits/attention_relational_report_v1/resource_measurement_v2/audit` and
`audits/attention_relational_report_v1/resource_measurement_v2/rate`.
This version makes at most one attempt per scheduled request: 537 plus 1,104.
No continuation, repair request, selective retry, adaptive cap increase, additional
rater or repeat-until-positive collection belongs to this version.

## Release and execution

Publish the registration, environment, metadata snapshot and exact manifest
drafts. A separate-context AI reviewer checks all current and published source
hashes, unchanged inventories and schemas, source-blind rater inputs, the resource
delta, settings and new roots. Its approval binds exact source bytes and each
stage's complete settings, request IDs, paths, lineage and output root. The final
manifest adds only its own review-metadata hash to the reviewed source map.
Publish and verify that release before executing the unchanged once-only runner.
This engineering review does not qualify the scientific theory or establish
independent annotator reliability.

Wait until both original batches are authoritatively terminal and preserve their
first execution receipts and outcomes before starting either new stage. This
avoids added API concurrency affecting the still-running first measurements.
A terminal failure is retained as such; it does not authorize resuming the old
batch. The new version still uses the entire fixed inventories, regardless of
which original responses completed or what their labels say.

## Assessment and interpretation

Collect, validate and summarize each version separately using the unchanged
pipeline. Preserve all first raw responses, claims, incomplete/refused/invalid
outputs, errors, missing positions and original denominators. Do not choose the
better response per item, replace original failures, pool versions as independent
cases, or combine their outcomes into a new pass rule. Compare instrument
completion and contract validity descriptively over the full fixed inventories;
any annotation agreement comparison uses paired positions with missingness
reported and makes no independent-rater reliability claim.

The original measurement keeps its primary summary. The resource-amended
summary is supplementary and explicitly repeated on the same 12 archived source
cases. Factual fidelity, COD/CA reference correspondence, source attribution,
causal controls, ordinary/analytic parity, templates, nulls and restoration are
reported for both, with their existing uncertainty and scope limits. No feature
labels, rubric, endpoint, threshold or theory-success criterion changes.

Complete instrument measurements can inform whether a fresh, powered
confirmation is justified. Neither resource acceptance nor repeated annotation
of the same prose achieves the source-of-qualia goal. That goal still requires
credible correspondence and selective source evidence, followed by prospective
confirmation and replication under the interpretation plan.
