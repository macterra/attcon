# Integrated-task factual review, development 1

2026-10-10. Prepared before task-case annotation. Extends the source-aware AI
review to the exported Controller query, command and response vocabulary. Human
review is optional. Existing factual and character first passes remain unchanged.

Use 16 synthetic statements with reporter-visible task records. Base records are
the frozen task-export examples; explicitly marked modified fixtures test withheld
history and joint abstention with one identified attribute. These are annotation
cases, not new Controller trials or new Reporter outputs. Preserve source bytes,
generation code, descriptions of mutations and input hashes before review.

Two AI factual reviewers annotate independently using the frozen
task-source inventory and quote-first procedure. They may have read the earlier
non-task development cases; record that exposure. They must not read task-case
author expectations or each other's task annotations before saving first passes.
Record every explicit proposition, its modality, exact quote/span, source pointer
and entailed/contradicted/unsupported/ambiguous outcome. An emitted response is not
world correctness; pending is not abstention; joint abstention is not two unknown
identities; a chosen command is not an executed command. History withholding is
not evidence of no execution when the execution flag is supplied.

Freeze these cases before assignment, preserve disagreements and compare complete
inventories afterward. This is semantic development rather than an automatically
passing qualification gate. Source-checking consensus can establish candidate
case answers with rationale, but not by treating original author expectations as
unquestionable gold. No threshold is selected from the annotations and no previous
pilot is rescored. New whole-prose task reliability, source-first coverage and
prospective pilot acceptance rules remain distinct deliverables.

Task reviewers are same-project AI contexts, potentially sharing model/training.
Procedural separation does not establish independent scientific replication or
human validation. Reporter and Controller remain separate. A report feature or
successful task response cannot establish consciousness by itself.
