# Readout dependency audit v1

2026-10-04. Post-hoc audit of existing [three-way interface](FUNCTIONAL_INTERFACE_RESULTS.md)
states, not a new Controller benchmark or reporter experiment. Publish source and
design before scoring. No checkpoint, input record, threshold or prior verdict is
changed. The goal remains credible source-of-qualia evidence, not consciousness
being necessary for task success.

## Question

The interface declares buffer 0 the category-decision source and mixes its learned
visual distributions with uniform uncertainty:
`p = q*visual + (1-q)*0.25`. Does command-dependent q change the dominant category,
confidence, thresholded identification, or an actually executed decision?
These are different notions of functional access; measure them separately.

For each color/shape component and any q>0, uniform mixing preserves ordering:
`p_i - p_j = q*(visual_i - visual_j)`. Its argmax therefore does not change in exact
arithmetic. Finite precision, five-decimal rendering, ties and q=0 are separate cases.
The audit evaluates real archived values rather than assuming arithmetic behavior
proves every rendered outcome. A classifier can still recover identity from a
low-confidence distribution; the reporting threshold can return null instead.
That is not by itself evidence for a validated consciousness-report construct.

## Fixed scope and measurements

Use all 512 episodes per model 2011/2021/2031, all three physical conditions, and
baseline/model-only effect-swap variants. Read the existing visual distributions,
current modeled recovery and four prospective command recoveries from the original
integration archives. Raw visual labels and true physical recovery are evaluator
comparisons, not substituted model inputs. The audited task readout is buffer 0.

For all 18 contexts, retain:

- Raw and five-decimal current/prospective categorical distributions.
- Raw argmax identities, their agreement with visual/scene identities, and any
  identity variation across the four commands.
- Identified color/shape according to the existing threshold 0.6 applied after
  Python five-decimal rounding; count command-dependent changes separately.
- Recovery minima, peak-confidence command ranges, and physical q=0 positions.
- Physical-counterfactual thresholded availability as a distinct evaluation array.

No success gate, sampling study, power claim or new scientific confirmation is
introduced. Count correlated episode/position/command views as descriptive array
entries, not independent trials. Archive every input-derived array, metric,
source/dependency/trace hash, and replay them without training or API calls. Refuse
overwriting an attempt and preserve all exceptions/findings.

## Interpretation limits and next implementation choice

This audits candidate decoders of an existing representation. It does not pretend
that an argmax decoder or thresholded abstaining classifier was already executing
as a native Controller in the three-way interface export. That export has no
category-action trace or delivered task outcomes. Prior bound-content control
queries are a different established assay and keep their verdicts.

If confidence changes while category identity is invariant, describe that result
directly. Future functional comparisons must specify and execute a decision rule
and its information access (for example, abstention or a concrete retrieval channel),
rather than infer task-access consequences from changing probabilities alone.
Any new boundary remains an engineered choice until tested; do not call it a
phenomenal boundary. A same-state decoder succeeding neither disproves internal
report fidelity nor establishes that consciousness is unnecessary or necessary.
Reporter and Controller remain distinct.

Independent rubric review and factual-audit qualification remain prerequisites
for new theory-facing reporting. This audit supplies neither human judgments nor
an interpretation chosen to make the source-of-qualia goal easier to satisfy.
