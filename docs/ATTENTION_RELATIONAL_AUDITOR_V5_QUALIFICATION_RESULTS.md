# V5 qualification fails: meanings and source citations remain distinct

2026-10-19. All first judgments and both independent first grades are retained.
The source-of-qualia objective remains unachieved.

The [prospective tool-assisted method](ATTENTION_RELATIONAL_SUBAGENT_AUDITOR_V5_PLAN.md)
uses two fresh reviewer streams, each with a separate context for the unchanged
24 short reports and four new dense fictional reports. The short key contains 65
mandatory assertions; the new key contains 350. Independent review approved every
new packet, assertion and operand before any auditor ran. These fictional tests
assess the measurement procedure, not consciousness.

All four actual contexts completed and saved56 first annotations. None was
replaced or repaired. First collection and mechanical derivation completed:

| Phase | Stream 0 | Stream 1 |
|---|---:|---:|
| Short mechanically valid |24/24|24/24|
| Long mechanically valid |1/4|1/4|
| Total mechanically valid |25/28|25/28|

Overall, 50/56 annotations pass mechanics. Each of the six rejected annotations
has an assertion with an empty required source-context list. The frozen core
rejects the whole annotation; the original first text, judgments and citations
remain unchanged. No source IDs are supplied afterward. The
[reference diagnostic](../audits/attention_relational_report_v1/subagent_auditor_v5/qualification/first_invalid_reference_diagnostic.json)
distinguishes empty lists from duplicate or unknown IDs. An earlier diagnostic
assumption and its failed assertion are preserved separately.

The whole release gate already fails because each long phase requires all four
annotations to be mechanically valid. No V5 target requests or judgments are
released. No automatic successor or repeated challenge is commissioned.

Both independent fresh graders completed all 56 positions, 830 mandatory assertion
opportunities and 918 actual assertions each. They agree on every primary and
diagnostic coverage, verdict, required-operand and reason judgment. Both short
phases pass: all 65 mandatory atoms per stream are inventoried and correct with
required operands, and all eight clean controls are accepted. Both long phases
fail.

In the primary assessment, 306 mandatory assertion verdicts are established and
correct; three lack required cited operands. The other 524 assertion opportunities
remain unestablished because their six annotations fail mechanics. The three
eligible citation deficiencies concern the experience claim in both streams and
the execution claim in stream 1. These correct `not_auditable` judgments omit
metadata pointers required by the unchanged key. They are not false experience
or execution conclusions.

The separately requested raw diagnostic review finds correct verdict meanings
for all 524 invalid-position atoms, but 12 required-operand deficiencies. Both
graders report no unsupported extra assertions or fabricated reasons in the
fictional challenge. This exploratory diagnostic was added after mechanics were
known; it does not upgrade primary eligibility, repair citations or qualify the
instrument. No population reliability or independent-system count follows from
agreement on these development cases.

The [first assessment](../audits/attention_relational_report_v1/subagent_auditor_v5/qualification/assessment/first_assessment.json)
checks exact input hashes, all position/atom/assertion identities, primary null
dispositions and both first-grade comparisons. It finds no atomic-field
disagreements; no adjudication was needed. Structural failure does not establish
that an assertion's meaning is false, and mechanical validity alone does not
establish factual correctness.

The software preparation retains its initial 11 passing fixtures and an independent
source review that found two readiness/retention gaps. Before any judgments, those
gaps were corrected and 16 amended fictional fixtures passed, including a complete
CLI round trip. Both source reviews, first executions and all calculator failures
remain available. Passing these software checks did not qualify the auditor.
