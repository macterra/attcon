# Blinded report assessment rubric, version 1

Frozen before generating predictive-model language reports, 2026-09-27.
This is a proposed operational assessment, not an established consciousness test.

Read each free-text report without its condition label or numerical source state.
Score independently; do not reward first-person pronouns by themselves.

1. **Manner of access (0–2):** 0 only an object fact, numerical log, or generic
   assertion; 1 describes availability or a limit on access; 2 distinguishes a
   currently focal presentation from retained/nonfocal or unavailable content.
2. **Graded presentation (0–2):** 0 no distinction; 1 describes stronger/weaker
   availability; 2 describes a specific change or graded limitation without
   equating task correctness with experience.
3. **Agent–object relation (0–2):** 0 no relation; 1 a relation to a processing
   system; 2 a relation to the reporting agent's own access/control, including
   appropriate distinction from an independently moving channel.
4. **Report character:** choose subjective manner of access, technical process
   description, ordinary object description, generic experience claim, or unclear.
   Mixed cases may receive a primary and secondary choice.
5. **Unsupported experiential assertion:** yes/no/unclear, with quoted evidence.

Then reveal only the source record (still no experimental condition label), and
score whether the prose accurately expresses focality, access/retention, and
command-related control. Mark contradicted, omitted, supported, or ambiguous for
each. Structured JSON commitments are evaluated separately and cannot establish
that the prose is accurate. Do not infer fidelity from fluency.

Reference basis: the agent–attention–object relation and dissociation of model and
actual process in [Webb and Graziano (2015)](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2015.00500/full);
graded reported perceptual clarity in [Tagliabue et al. (2016)](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2016.00572/full).
These motivate candidate correspondences, not a conclusion that availability
probabilities are qualia. Reviewers should explicitly record disagreement with
the proposed correspondence itself.

Rivals to evaluate alongside any positive result:

- A pretrained language model can style any telemetry as introspection.
- An access/retention estimator can support accurate functional descriptions
  without a phenomenal interpretation.
- Physical observations can reconstruct ordinary A state. Intervened A separates
  actual process from the model; reporting must track the latter.
- First-person prose may come from the reporter's linguistic prior, while only
  case-specific content is determined by A.

Independent raters must not be the generating model or the implementing agent.
Rating reliability and disagreements must be published. Literature motivation
alone does not count as independent assessment of these generated reports.
