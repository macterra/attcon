# Attention-dependent content form: mechanical primitives v1

2026-10-10. **The toy-state mechanical milestone passes after a preserved
restoration correction.** This is engineering feasibility, not learned attention
modeling, source semantic qualification, report correspondence or qualia evidence.

The [implementation](../scripts/attention_content_form_primitives_v1.py) stores
addressed retained sensory maps V and separately completed internal maps W.
Block averaging at bandwidths 1, 2 and 4 changes selected W using saved V, while
preserving original sensory evidence, literal identity records and raw logits.
Current completed state, pure analytic operator alternatives and audit history
have separate exports. The matched exogenous driver performs the same numerical
operation; driver provenance is omitted from diagnostic state exports. A known
operator baseline explicitly declares oracle mapping knowledge.

passes 12/12 checks. The [independent first pass](../audits/attention_content_form_primitives_v1/independent_review/review.md)
passes 8/9 and identifies an accepted-input defect: restoring a directly
constructed float32 buffer rounded its immutable Python tuple values, despite
identical tensor values and exports. That complete-state inequality was committed
at `c3699e2` before repair. Original code, receipts, fixture and failed log remain
preserved in history and as separate first-pass artifacts.

The [correction receipt](../audits/attention_content_form_primitives_v1/correction_receipt.json)

first-pass files remain byte-identical to their preservation commit.

These checks establish copied ownership, address isolation, numerical operators,
time distinctions, exact saved restoration and matched driver behavior on toy
maps. They include no checkpoint loads, model fits, production inference or
