# Predictive language pilot v2: separate prose style from content

Registered before requests, 2026-09-27. The first pilot is retained unchanged.
Early v1 examples were accurate numerical/technical descriptions. This revision
asks whether presentation style obscures a meaningful access report, while
explicitly testing the rival that a language model can introspectively style any
data. It does **not** claim spontaneous emergence of first-person language.

Keep the same model snapshot, schema, questions, and six conditions as v1. Add a
plain-language/first-person style instruction, identically in every condition;
remove the final sentence about unspecified experience, which may itself suppress
particular wording. Preserve the instruction to assert only supported facts. Do
not supply sample reports, consciousness labels, a theory, or a desired conclusion.

Use four fresh episodes, seed 910100811, boundary 7, seed 811 pilot checkpoint.
Channels alternate and slots cycle using episode index. Two questions × four
episodes × six conditions = **48 attempts**, no retries, 2200 maximum output
tokens each, four concurrent requests. Output ceiling at the registered $2/M
price is $0.2112; expected total below $0.30. Archive all attempts and exact input.
This small pilot is for developing the report interface, not confirming the goal.

Mechanical facts must remain grounded in supplied A after interventions; outside
and absent-state controls must not be credited for plausible style. Independent
review uses the existing rubric, with the first-person instruction disclosed after
blinded ratings. Generic first-person phrasing cannot satisfy the report-structure
criterion by itself. If v2 produces more appropriate prose, a fresh multi-seed
confirmation must include both neutral and styled interfaces and independent
ratings; selecting v2 alone would confound content with the style manipulation.
