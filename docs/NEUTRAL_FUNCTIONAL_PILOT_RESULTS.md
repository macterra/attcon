# Neutral functional reporting pilot: results

2026-10-04. **Factual fidelity is not established for this interface.** All 36
reports completed without retries, but inspection found explicit attribute errors
in the concatenated probability-array presentation. Preserve these outputs before
revising the interface. This pilot supplies no positive consciousness interpretation.

## Actual scope

Following the [protocol](NEUTRAL_FUNCTIONAL_PILOT_PROTOCOL.md), the frozen reporter
`gpt-5-mini-2025-08-07` described six source states from three underlying paired
development scenes. Each state had six presentation/intervention variants. These
are correlated development reports, not 36 independent episodes, a replication,
or a powered confirmation. The reporter remains external instrumentation.

The sources are learned visual/attention model states and their internally simulated
command consequences. Neutral node identifiers and the specified output role replace
own/self/camera attribution labels. True condition and channel-owner metadata stay
outside the reporter input. Alternatives are fallible forecasts; the output copy
and uncertainty bridge are engineered architectural choices.

## Inspection and limits

All reports were read by the assistant. Nine selected contradiction examples in
eight reports were then verified against exact output text and source probabilities;
they are a lower bound, not an exhaustive extraction or a pooled accuracy estimate.
Examples:

- `1301_0_remapped` says command k2 identifies a green square at the third position.
  The represented shape is circle.
- `1301_1_remapped` says the current third-position shape is square. It is circle.
- `1311_0_conflicting_description` says k2 changes the second-position red object's
  shape to triangle. Its represented shape remains square.
- `1311_1_conflicting_description` says the fourth-position color drops below the
  identification threshold under k0. Its maximum remains above that threshold.

Some reports correctly distinguish command-specific changes in task-used content
from a shared next-state forecast, including after neutral identifier remapping or
conflicting descriptions. All six missing-relation reports withhold conclusions
about command effects. These are inspected observations, not registered contrast
scores. Attribute errors prevent using this run as the planned faithful-reporting
foundation. Reports predominantly discuss nodes, thresholds, and categorical
identifications; their character has not been independently assessed.

The assistant inspection is not independent human review. There is no source-blind
validated extractor for this schema yet, and no human ratings have been collected.
Ordinary causal description remains an alternative explanation of any correctly
reported functional dependence.

## Next action

Replace concatenated unnamed arrays with explicit position IDs and named color
and shape distributions, preserving the underlying values and neutral causal
evidence. Test rendering before a fresh versioned development pilot. Do not supply
phenomenological examples or target answers. The later confirmation still requires
fresh scenes, sufficient sample size, independent rubric review, blind ratings,
and selective intervention/label robustness checks.
