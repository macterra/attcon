## Pre-data instruction amendment

Process auditor v3 adds one stricter requirement: selection-forecast presence claims
require explicit prose about whether an allocation/selection forecast, distribution
or prediction/readout is supplied, provided, present, missing or absent in the record.
An unstated/unspecified selected value alone does not establish that no forecast
exists. Omitting a forecast from the report does not establish its absence from the
input. A supplied forecast with an unidentified selection remains distinct from
missing forecast information. Apply this rule to current and command statements and
to all node IDs; never repair positive readout-selection claims by assuming the
architecture. Auditor receives numbered prose only, not source or condition.

Retain all 32 prior process fixtures and original expectations. Add four boundaries:
unstated selected value, explicitly unidentified model selection, explicitly supplied
forecast with unreported selected value, and omission of a forecast from the report.
All **36/36** must pass before report generation or process extraction; any failure
halts this version without retry, replacement or altered expectations. Categorical
v1 retains its separate 14/14 fixture prerequisite. Typed schema and local validator
remain unchanged; structure alone does not guarantee semantic truth.

Reporter remains `gpt-5-mini-2025-08-07`, medium, 8192 output tokens, 180 seconds,
concurrency 6. Process auditor remains `gpt-5.4-2026-03-05`, medium, 16384 tokens,
240 seconds, concurrency 6. Categorical auditor is the same snapshot with low
reasoning and the same output/timeout/concurrency limits. No retries in any task.
Commit/publish protocol and unchanged inputs before calls; preserve raw-report and
assessment milestones afterward. Archive and replay all complete/incomplete attempts.

is distinct from confidence or felt clarity. Reporter is separate from Controller.
Solicited factual attention domains cannot count as spontaneous emergence. Character
judgments remain descriptive machine judgments. Independent rubric review, blinded
human assessment, powered confirmation and replication remain outstanding under the
[interpretation plan](CONSCIOUSNESS_INTERPRETATION_PLAN.md). Earlier failures are
never rescored into successes. A technical-only result provides no automatic support
