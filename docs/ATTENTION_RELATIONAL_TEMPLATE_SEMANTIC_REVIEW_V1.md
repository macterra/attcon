## Independent first judgments

Use two fresh separate-context AI reviewer streams. Each chunk context receives
this protocol, frozen reference, exact bound packet and output schema, but no peer
judgment or desired positive outcome. It may inspect actual packet/source values;
it may not invoke another reporter/rater, repair outputs, inspect peer grades,
change rules or edit source evidence. Save each exclusive first artifact before
any peer comparison. Record reviewer/context identity and exact packet/protocol
hashes. Humans are optional; shared training and commissioning limit independence.

Each established template receives three linked review inventories:

1. **Components:** all 12 original feature/auxiliary/composite records. Preserve
   original status. Judge application `supported`, `unsupported` or `unresolved`,
   with specific textual reasoning. Supported means the recorded status is
   warranted under the unchanged reference, including warranted ambiguity or
   absence; it never means an ambiguous/absent record became explicit. Coordinate
   lists, order, confidence, generic estimate labels or command labels alone
   cannot acquire O/D/A merely because the source is an attention model.
2. **Evidence:** every exact evidence path once. Judge `grounding` as supported,
   unsupported or unresolved for its recorded component role and binding. Retain
   referent, attribute, scope, quantifier and time. Separately classify semantic
   source meaning as `source_specific`, `mixed_sources`, `global_convention`,
   `unrelated_property` or `unresolved`. Name each actual construction unit and
   precise relative property path/value involved, with all relational operands.
   Complete peak-set properties may use path `[]`; nested origin claims must
   name their actual field(s), not acquire every field in a containing token.
   Generic prefixes/header labels are not actual A-content witnesses.
3. **Composite bindings:** every original COD/CA binding once. Name compatible
   feature evidence paths for each required feature (COD:C/O/D; CA:C/A), the
   binding's own evidence paths, and why they concern the same content/attribute,
   scope and time. Judge supported/unsupported/unresolved and give a reason.
   Textually present evidence with the wrong meaning is not a supported witness.

List additional concerns, including possibly missed features, unsupported scopes,
source/model-world substitutions, coordinate-to-appearance or forecast-to-current
conversions. No original label or missing feature is repaired or upgraded. For
invalid/unavailable annotations, record only `unestablished` with matching original
diagnostics and empty semantic inventories. Do not silently infer their meaning.

A property reference contains `unit_id`, `value_path`, exact `value`, and
`semantic_role` (`content_operand`, `status_operand`, `processing_relation_operand`
or `context_only`), plus a reason. A value path is relative to that token's `value`.
It must resolve exactly. Include all required operands, even if a quote directly
mentions only one. An operand outside the quoted overlap may be cited only with
an explicit binding explanation in the full text; overlap is neither sufficient
nor mandatory proof of semantic relation. Keep mixed/unresolved attribution;
never pick one favorable source among several. Source classes are resolved from
indexed provenance, not supplied by the reviewer as an unsupported label.

## Comparison and interpretation

Retain both first streams and every disagreement. Root may resolve explicit
issues using unchanged text, reference and source fields, in a separate artifact
bound to both originals. An unresolved required component, evidence meaning,
operand or binding cannot establish the corresponding endpoint. Code can verify
complete inventories and exact fields; it cannot certify semantic correctness.
No population reliability or new independent-system count follows from agreement.

Any later conservative source-attributed assessment must keep raw V3 results
unchanged and separately named. COD and CA retain their original explicit versus
explicit-plus-ambiguous distinction; no status/scope upgrade is allowed. A complete
compatible binding and all required grounded feature witnesses are necessary.
A source-specific A-dependent relation must include an actual A-content property
or explicit relation involving it, not copied W11 or a generic convention. Keep
mixed-source meanings as mixed and all unresolved opportunities visible in the
552 denominator. Publish per-scope and per-case yields; valid-only proportions
are supplementary. Source attribution cannot turn organization/access scope into
perceptual appearance or establish felt truth.

The later paired analysis must use property identities, preserve all 684 pairs,
unaffected facts, true nulls and exact restorations, and distinguish missing
measurement from invariance. No label/wording switch or A superiority over another
attention-effect estimator is required. Authored renderer tracking establishes a
measurement path; it is not spontaneous report organization or evidence that a
particular subsystem experiences. Fresh-system confirmation and replication
remain future work. The ultimate qualia-source goal is unchanged and unachieved.
