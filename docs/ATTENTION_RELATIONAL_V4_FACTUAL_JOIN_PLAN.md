# Separate V4 factual / V3 reference assessment

This prospective development plan fixes a new whole-version assessment before
any V4 target audit. It does not replace the original primary result or V3's
previously selected resource-v2 factual substrate. The original aggregate results
and instrument failures are known; the running V3 reference labels have not been
inspected. No V4 target response exists. The goal remains credible evidence for
the attention-control-model source of qualia, beyond engineering readiness.

## Honest reference join

Reconstruct V3 grounding from the actual raw first collection, requiring its
real requests, lineage, transport and actor-text checks. Bind the first V4 factual
assessment and its actual source/request/response provenance. Join by original
text ID, exact text hash, case and arm; the two instruments' opaque API IDs need
not be equal. Reject a mismatch or failed provenance check rather than filling
results from another version. Derived evidence is not a raw old-format response.

Report raw COD and CA independently of factual fidelity. Then report their
conjunction with the complete V4 two-auditor factual decision; each auditor's
separate conjunction is supplementary transparency. Preserve all scope and time
labels, auxiliary features, invalidity and missingness. Keep denominators of 552
per arm and twelve archived cases; repeated views, annotations and extracted
assertions are not independent systems. Explicit and explicit-plus-ambiguous
counts are descriptive conventions, not confidence intervals or bounds over
unknown judgments.

The earlier V3/resource-v2 factual join must still be computed and retained under
its original whole-version preselection, including zero established narrator
fidelity if that remains its result. A more informative V4 assessment cannot
silently replace it or convert any original failure to success.

## Source interpretation and causal controls

A faithful report with a reference feature is not automatically evidence about
the attention model rather than copied world-model fields. Preserve the actual
exported origin of each relevant operand: current or conditional source estimates,
inherited estimates, copied W11, native W or sensor data. Ordinary is another
initialization of the same attention-effect model architecture, and analytic
models the same command effects differently; their parity is not an
attention-model-absent comparison.

Any automated origin mapping must retain all matching assertions and operands
from both auditors. A sentence span can contain several distinct assertions;
mere containment of a reference quote in that span does not prove which
assertion earned the reference feature. Record-scope citations cannot expand to
all nodes, and a role-relation context expands only its explicit operands.
Keep mixed and unresolved mappings visible. A semantic source-link claim needs
an independently checked match between the actual reference evidence, assertion
meaning and source contexts; geometry alone supplies descriptive diagnostics.
Such review may use AI contexts and must preserve first mappings/disagreements.
No unresolved descriptor earns source-specific correspondence.

Use the complete predeclared donor, fixed-source W-change and restoration pairs.
Source tracking concerns the reported property, not a wording change or mandatory
COD/CA category switch. A changed distribution can retain its peak set, and a
restored input can receive different wording. Keep those nulls and distinguish
invariant source facts from unavailable paired measurement. The source's bounded
forecast/control role remains separate from the Reporter and native Controller.

Report what each scope warrants. Model-access/organization correspondence is a
limited structural analogue; appearance wording alone is not a native appearance
counterpart or verified experience. A source-linked positive can motivate the
[fresh confirmation and replication](ATTENTION_RELATIONAL_CONFIRMATION_DESIGN.md);
these twelve development cases, even with qualified auditing, do not complete
that work or uniquely identify a quale-generating locus.
