## What is compared

Each peak property retains the complete exact maximal-cell set, its raw 4×4
distribution path and content hash, and actual source provenance. Individual
nested origin fields remain separate properties. Source identity comes from the
archived provenance and origin chain, including copied W versus learned A,
ordinary and analytic estimates. Panel names, token numbers, offsets and rendered
wording do not determine property matching.

Comparability retains the addressed panel/view/command/node/role, actual source,
operator, origin category/kinds, decision time and each individual temporal origin
coordinate. Represented time does not replace record, feedback, shown, archived
or nested inherited time. Every indexed value and raw distribution path must
select that exact addressed node and role, even when another node has equal peaks.
The complete peak set is recomputed independently of the stored derived field.

These are numerical identities. The source-aware reviewers must still establish
what a report asserts and whether its exact content, attribute, scope and time
are compatible with particular operands. The bank reads no reference annotations
or semantic judgments. Its author knows prior V3 aggregates and narrator closure;
this implementation is informed development under the earlier fixed analysis,
not a new output-unexposed experiment. Ordinary and analytic also estimate
attention effects; their parity is not an attention-model-absence contrast.
