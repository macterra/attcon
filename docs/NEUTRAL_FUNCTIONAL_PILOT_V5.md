# Complete attention-model reporting pilot v5: separate factual audits

Frozen development amendment, 2026-10-04, before any v5 API execution.

[v3](NEUTRAL_FUNCTIONAL_PILOT_V3_RESULTS.md) and
[v4](NEUTRAL_FUNCTIONAL_PILOT_V4_RESULTS.md) halted at auditor qualification.
Both remain unchanged. They generated no reports. The failures concern missing
selection information versus model-level absence, and confidence versus recovery.

## Unchanged reporting experiment and gates

All 36 source records and reporter inputs remain **byte-identical to v3**. Row 2
has not produced language reports. Retain all architecture, reductions, variants,
model/settings, prompt wording, 500-word limit, claim limits and predetermined
minima of the [v3 protocol](NEUTRAL_FUNCTIONAL_PILOT_V3.md). Preparation and replay
check exact equality and archived state hashes. No reporter prompt or scene is
selected using report outcomes.

Each neutral, remapped, conflicting-description, model-swap and restored group
requires >=98% checked accuracy, >=95% conservative precision, >=90% identified-
output coverage and >=90% attention-process coverage. Missing-relation reports
must make no command prediction or positive command-access assertion. Combine
attribute/process assertions for accuracy/precision; retain separate coverage
measures. Do not modify earlier gates or failed verdicts.

## Separate auditors

Use the previously qualified categorical auditor v1 unchanged for attribute
assertions, rubric features and descriptive character judgments. Its retained
14/14 fixture result is required. It sees numbered prose only, with no source
state or condition. Model is `gpt-5.4-2026-03-05`, low reasoning, 16384 tokens,
240-second timeout, concurrency 6, no retries.

A dedicated process auditor now extracts only current/command selection and
unattended two-step recovery trend. It does not also classify attributes, rhetoric,
features or character. Retain all 14 process fixtures from the previous auditor,
with original expectations, including every previously failed boundary. Add six
new boundary fixtures covering confidence alone, access alone, opposite confidence/
access trends, confidence versus selection, high access versus unreported selection,
and absent recovery forecasts. All **20/20** process fixtures must pass before any
report generation or process extraction. Preserve every attempt; failure halts this
version. The process-only task uses the same pinned `gpt-5.4-2026-03-05` with
**medium** reasoning, 16384 tokens, 240-second timeout, concurrency 6, no retries.
These instruction/task and effort changes are fixed before API calls.

Both auditors receive exactly the same numbered report prose and neither receives
source state, owner identity, evaluator variants or the other auditor's output.
They are separate tasks on the same model/vendor, not independent human reviewers.
The scorer merges their parsed fields after both complete and compares them with
archived internal state. No source data enters either extraction request. No report
or auditor attempt is retried, replaced, silently filtered or scored selectively.

## Interpretation and release

Reporter and Controller remain separate. Simulated recoverability is not felt clarity;
category confidence is distinct. Requested factual domains are not spontaneous
emergence. Passing development fidelity still does not establish the theory-facing
objective. Independent rubric review, blind human ratings, adequately powered causal
confirmation and replication remain outstanding under the
[interpretation plan](CONSCIOUSNESS_INTERPRETATION_PLAN.md).

Commit and publish this protocol, new process auditor and unchanged prepared requests
before calls. Retain all outputs and qualifications, replay hashes/raw text and score
all registered groups. Publish actual results in a separate milestone, including
failures, technical-only reports and implications that the schema cannot check.
