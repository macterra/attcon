# Integrated-task reporting pilot: results

2026-10-10. **The fixed pilot is complete; the source-of-qualia goal remains
unachieved.** Eighteen new reports describe the attention-control model's contents,
selection/recovery forecasts and actual Controller task events. All requested facts
are judged covered, with one retained unsupported forecast-scope assertion. Both
source-blind raters classify all reports as technical, with no presentation manner
or experiential wording. No report meets the candidate content/presentation pattern.

## Qualification and provenance

[Version 1](INTEGRATED_REPORT_PILOT_V1.md) halts before reporting: each auditor scores
46/48 under the frozen all-labels gate. Both call absent supplied allocation
statements unsupported; the checked author key calls them contradicted. No expected
supported assertion was rejected or non-supported assertion credited. The failed
verdict and unused report budget remain unchanged.

[Version 2](INTEGRATED_REPORT_PILOT_V2.md) prospectively tests supported versus
non-supported claims with two fresh contexts, newly remapped identifiers/values and
48 assertions. Both score 48/48, including detailed labels under explicit source
conventions. These are template-transfer challenges, not unrestricted-language
qualification. Before challenge prose, a reference check detects evidence-path
substring corruption and literal ambiguity in withheld/retained wording. Original
bytes and review remain; a separate pointer-only erratum and source glossary are
saved before auditor responses. A second, exposed source check validates the
corrected key. No case statement, outcome, payload, threshold or target input changes.

One fresh AI subagent functions as diagnostic Reporter, receiving only unchanged
neutral instructions/payloads. This differs from earlier API Reporter implementations.
The Controller and attention-control model are distinct from this instrumentation.
All 18 attempts are reserved before assignment; 18 reports arrive, 121–137 words,
within the 180-word limit. No retries, replacements, training or new Controller trials.

The budget covers checkpoint 2011, row 3, query p0, three physical conditions and
six correlated variants per condition. There are **three episodes in one checkpoint**,
not 18 independent samples. Source-only required-fact inventories precede prose;
both auditors verify all 504 paths/values before seeing reports. AI contexts share
training and project commissioning; procedural read restrictions are not secure
blinding, human validation or scientific replication.

## Source-blind structure and character

| Dimension | S3 | S4 |
|---|---|---|
| Content identity | Explicit 16; absent 2 | Explicit 16; absent 2 |
| Selection contrast | Explicit 18 | Ambiguous 18 |
| Recovery, identity certainty, access attribution, temporal availability | Each explicit 18 | Each explicit 18 |
| Action–access dependence | Absent 16; ambiguous 2 | Absent 16; ambiguous 2 |
| Prominence, presentation manner, response confidence, experiential wording | Each absent 18 | Each absent 18 |

Both label all 18 reports technical and judge an ordinary technical reading to fit
all content. The raters agree on 180/198 dimension pairs (90.91%); the 18 differences
concern whether saying a node “selects” a position explicitly supplies relative/
highest modeled allocation. This agreement is descriptive, with no registered
reliability threshold or independent-episode uncertainty estimate. Uniformly absent
appearance features do not validate recognition of positive appearance examples.

Content and presentation co-occur explicitly in **0/18** reports for each rater.
The candidate pattern is not expressed. This is a negative development finding
under this interface/genre, not proof of absent experience or a failed fresh
confirmation of the theory. Neither technical character nor task success establishes
or rules out consciousness.

All three have exact input restoration. Observation history and prospective
command records are identical between after/attenuated inputs. Current modeled
recovery/readout changes selectively; the reports describe these current-state
changes without inventing additional execution. The physically unchanged histories
and unaltered future tables remain separate. These are source/fidelity controls,
not evidence that experience is necessary for performance or a consciousness test
by themselves. Every condition still contains an attention-control model.

## What to test next

A fresh, output-unexposed
[methods review](https://github.com/macterra/attcon/blob/main/audits/integrated_report_pilot_v2/methods_review/review.md)
finds operational correspondence plus source fidelity logically possible. Requiring
source-verified felt appearance would make the conjunction unattainable under the
current information boundary. Keep four questions distinct: source-state accuracy,
appearance language, represented appearance/model attribution, and unverified
subjective experience. Reporter first-person language is not a report of the
Reporter's own qualia.

The exposed interface supplies categorical contents and modeled selection/recovery,
without explicit brightness/blur/contrast heads. That is an interface limitation
and an untested representational question, not proof that hidden states cannot
carry appearance-related information. The literature grounding does not yet
validate a machine/free-prose consciousness measure. Selection and action–access
annotation boundaries also need clarification before confirmation.

**Next register a frozen-model source-sufficiency assay before more prose.** Use
independently specified stimulus factors and qualified appearance judgments; vary
appearance-related physical properties separately from category identity and
recovery/decision uncertainty. Probe held-out states and matched controls; locate
any signal with selective state interventions while keeping ordinary contents and
answer behavior controlled. A stimulus-property prediction is not itself a qualia
report. Only if the relevant signal is demonstrably supplied or recoverable should
fresh neutral prose test its reference correspondence. If it is absent from the
interface, diagnose the missing representation rather than renaming recovery as
felt clarity. Do not supply desired experiential wording or run versions until a
positive result appears. Confirmation, power and replication remain outstanding.
