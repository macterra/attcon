# Functional wiring development assay

2026-10-04. Development specification before execution. This validates causal
identifiability, not report character or consciousness. No language reports are
generated by this assay.

Two four-slot content buffers start with identical categorical distributions.
Both have the same acquisition and decay dynamics. A command chooses which slot
one buffer samples; the other follows an independently scheduled slot. In the
own-access condition commands affect buffer 0, which supplies the task's answer
distribution. In the external-device condition commands affect buffer 1; buffer 0
still supplies answers and follows its independent schedule. A decoupled condition
uses independent schedules for both. The decision readout is fixed across
conditions. These functional roles define the comparison; calling a buffer an
external device is not empirical evidence that it is outside a conscious boundary.

At a shared initial state, execute every alternative command with matched noise,
quality, and independent schedule. Query each slot's category through the fixed
decision readout. Record both buffer distributions and output distributions.
Only commands, neutral node IDs, slot IDs, and distributions enter the diagnostic
payload. No condition name, own/self/camera/attention label, controllable-buffer ID,
or explicit edge list enters it. Permute node presentation order and identifiers
independently of physical condition. The evaluation truth stays in a separate file.

The developmental rule-based observer identifies whether changing commands changes
task output, another buffer alone, or neither. This verifies the available causal
evidence; it is not a learned reporter, a positive phenomenology result, or a
theory-discriminating baseline. Test 128 paired seeds, all 6 node permutations,
and all three conditions. An initial-state-only payload must be identical across
the three conditions for a given seed/permutation. Equal priors then bound any
classifier of those identical payloads at 1/3 accuracy.

Minimum engineering checks: an alternative command must leave the independent
buffer exactly unchanged; it must change the controlled buffer. Output changes
must equal the changes in buffer 0. Decoupling must remove every command effect.
Matching initial states and neutral identifier permutations must be preserved.

This fixture deliberately uses categorical sensor evidence to isolate wiring.
The existing learned visual encoder and attention predictor are not yet integrated;
these synthetic buffers must not be represented as a replacement confirmation of
that learned model. Next integrate a learned predictive model and establish its
factual fidelity before producing neutral prose. Keep world-state outcomes and
fallible represented predictions separate in that integration.
