# Bound-prose confirmation v2: sentence-grounded audit and temporal indexes

Frozen before v2 reports, 2026-09-27. Confirmation v1 remains failed. Checked color,
shape, focality, and most-recoverable assertions are generally accurate, and 45/48
ordinary/binding reports are classified subjective_access or mixed. Nevertheless,
coverage, paired relations, agency evidence, one temporal-direction gate, and
missing-component checks fail. Do not replace its recorded verdict.

Inspection finds two measurement errors: the extractor fabricates ellipsized
quotes, causing correct prose to lose credit; it sometimes treats explicitly
possible alternative shapes as asserted dominant shapes. It also mistakes "stays
low" for equal probability over time. Some reports genuinely overgeneralize that
all recoverability values decline, whereas a learned low-probability forecast
occasionally increases. Both measurement and reporter errors are retained.

## Changes

Keep all v1 thresholds, models, ten conditions, question, and request settings.
Use fresh process seeds410010000+visual seed and scene420010000+visual seed, eight
episodes per model. Add exact per-object endpoint temporal direction to the
transparent indexes already supplied, alongside all original probabilities.
Explicitly distinguish dominant identity (maximum >=.6) from possible alternatives.
These are deterministic interface facts, not phenomenological labels or examples.

Extractor v5 sees the same prose split into numbered original sentences and cites
sentence IDs. The evaluator resolves each citation back to actual text; nonexistent
IDs fail. This removes quote-copying errors without accepting paraphrased evidence.
Extract dominant versus possible identity assertions separately: dominant claims
must match an identified representation; explicit possibilities require nonzero
probability in the supplied state and cannot earn identified-object coverage.
Missing source distributions cannot support named possibilities. Preserve other
fields and existing thresholds. Do not infer temporal equality from a qualitative
band remaining low or from selection/access independence.

Validate17 fixtures before using v5, retaining prior fixture outcomes. Then run
240 new reports and240 condition-blind extractions. Reporter maximum8192 tokens,
extractor maximum8192, no retries, concurrency8, timeout120seconds. At registered
prices, output ceilings are$3.93216 for generation and$16.842752 for257 extractor
attempts; expected total is substantially lower. Record actual usage.

Positive correspondence criteria remain object-linked access, focal/background
contrast, graded/temporal availability, and agent-object relation, separately
from character classification. Use the same .75 thresholds and all fidelity,
coverage, paired-intervention, restoration, and missing-component gates from v1.
Automated judgments are not human validation or proof of subjective experience.
