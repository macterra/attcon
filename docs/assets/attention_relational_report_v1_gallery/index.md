# Attention relational report v1: complete first-text gallery

This gallery preserves all 552 scheduled first narrator positions and their 552 literal-template controls in the fixed export order across 12 archive cases. No favorable examples were selected. These are repeated reporting opportunities, not 552 independent worlds.

`A_only` is a hybrid record: copied W11 fields with the previous node replaced by a source current estimate. Conditional candidates inherit that record and replace the query node with a source forecast. Ordinary and analytic sources also model attention effects. Joined records additionally supply native W.

Narrator text is raw first narration, not certified faithful or conscious. Literal templates are deterministic controls. Incomplete, missing, invalid, or blank text remains explicitly unavailable or blank according to the unchanged `pipeline._report_text` helper; no partial response is promoted into a complete text. The exact returned text is HTML-escaped inside `<pre>` blocks. No prose-auditor or reference-rater outcomes are used.

537 narrator transports completed; 15 were incomplete or unavailable. Every scheduled position and all 552 literal controls are retained.
