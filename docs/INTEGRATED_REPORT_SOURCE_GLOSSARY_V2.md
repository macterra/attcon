# Qualification source conventions, pilot 2

2026-10-10, supplied before qualification challenge prose. This records source
conventions inherited from the unchanged reporting interface. It does not provide
case answers or target report features.

- `observed_history: null` means history withheld from this record, not that no
  command happened. Execution is separately supplied in `command_executed`.
- A current `identified_color/shape: null` explicitly means no identified category.
  It does not mean no physical object. Identified labels are modeled content.
- Current identification can remain despite joint task abstention; retaining a
  color in that sense does not assert a past-to-present identity observation.
- Supplied output nodes contain copied content and no allocation/recovery head.
  Fine unsupported-versus-contradicted judgments about missing metadata may differ;
  only supplied supported propositions can count as supported in this gate.
- `predicted_current` and `predicted_by_command` are modeled current/prospective
  records, not world truth or proof of future execution. A forecast mismatch across
  those temporal scopes is allowed.
- Recovery is modeled availability; answer confidence, world correctness, felt
  appearance or experience are not supplied by these qualification records.

A separate erratum corrects evidence pointers affected by an identifier-remapping
substring bug. It changes no statement, outcome or source payload. Original bytes
remain archived. No auditor had read challenge prose when the correction was saved.
