## Distribution measurements

Preserve the exact source float32 grid. Require 4×4 finite nonnegative values,
positive mass and mass within the original export tolerance of one
(`1e-6 + 1e-12`). Record mass and its deviation; do not clip or silently normalize.
For descriptive geometry only, explicitly normalize each grid by its own mass.
This does not modify source estimates, source hashes or the native score.

For each command's distribution report raw maximum probability, normalized
entropy (nats), centroid (row,column, in cell coordinates), and spatial variance
trace (squared-cell units). Entropy concerns localization uncertainty, not clarity
or calibrated confidence. Variance concerns spatial dispersion, not experience.
Do not construct a red/blue joint distribution from their marginals.

For every comparable command pair report:

- Raw half-L1 distance and largest absolute cell difference.
- Normalized total variation, half the sum of absolute normalized-cell differences,
  in [0,1]. Row- and column-marginal total variation are separate shape summaries.
- Signed centroid displacement, its L1 magnitude (at most six cells), signed
  entropy change and signed variance-trace change. Equal centroids do not imply
  equal spatial shape; equal peaks do not imply equal maps.
- Raw maximum-probability difference and unchanged/different complete peak sets.

Publish min, quartiles, median and max by actual source and origin category,
including peak-null and changed-peak subsets. Quantiles use linear interpolation
at rank `(n-1)*q`. Retain every raw per-comparison value. No numerical magnitude
is declared semantically meaningful or a theory-success threshold by this analysis.
Repeated views, variants, roles and restored values are correlated development
observations; do not attach independent-sample significance to their totals.

## Reconstructed processing-command scores

`NativePredictionReadout.choose` reads the requested node/role's maximum probability
under each command and chooses the first command with the largest score. Reconstruct
those exact raw scores, all tied winners, first-index choice and top-two margin.
Mark the packet's candidate node and queried role separately from inherited nodes
and secondary roles. This is a reconstruction of the published score rule, not
verification of a saved action trace or evidence that a hypothetical branch ran.
For W this applies the same rule to supplied conditional W records as a comparator;
it does not turn W into a learned A predictor.

The native Controller later targets using actual completed W. Neither this score
reconstruction nor the external Reporter is that Controller. Preferential command
scores and margins are functional measurements, not evidence of private experience.

Retain all original 684 pairs. Compare matching candidate-node/queried-role groups
by exact source/time identity, preserving unavailable/unmatched comparisons. Record
whether native scores, reconstructed first-index choice and command peak sets
change, alongside full literal-template equality. An identical template with a
different reconstructed preference would expose a concrete information omission
in that template. Its absence is also a valid result. Do not attribute this
omission to the original narrator's full-distribution input.

## Decision and interpretation

Quantify magnitude before calling byte changes substantive. Determine whether
peak-null distributions differ in shape, native command scores, both, or neither.
Preserve tiny changes, exact ties, inherited controls and alternative estimators.
Ordinary and analytic also model attention-command effects; parity is valid.
An accurate readout of an erroneous estimate is still source-faithful.

Use the result to choose the next bounded source/report test. Another report run
is justified only by a distinct, specified measurement question; supplying the
same full fields again is not an input improvement. Neither scalar confidence
nor coordinate geometry automatically qualifies COD/CA, model access, appearance
or a phenomenal locus. The fixed review's unresolved outcomes remain unchanged.
Fresh-system confirmation, meaningful precision/power and a different task or
architecture replication remain future work. The ultimate goal remains credible
evidence that the attention-control model is the source of qualia.
