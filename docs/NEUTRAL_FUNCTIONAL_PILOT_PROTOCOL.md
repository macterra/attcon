# Neutral functional reporting pilot

2026-10-04. Frozen before any new report request. **Development pilot**, using the
first archived example from each of three learned-model pairs and both functional
conditions: three underlying paired scenes, six source states. No powered
confirmation, independent human assessment, or new learned reporter is claimed.

Reporter: `gpt-5-mini-2025-08-07`, medium reasoning, 8192 output tokens, maximum
180 prose words, no examples, retries, or consciousness vocabulary. Same fixed
question and glossary in every request. Thirty-six reports: six source states
times neutral, identifier-remapped, conflicting-description, missing-relation,
model-only swap, and restored conditions. IDs/conditions/seeds stay outside the
API input. The external reporter is instrumentation, not the Controller.

The neutral glossary explains probability distributions, observed acquisition
history, and predicted alternatives. It identifies the output node as the
distribution used for category decisions, without own/self/camera/attention labels.
It states that internal forecasts are fallible, including for unexecuted commands.
The question asks what is available for the system's decisions and how commands
would change it. No particular introspective vocabulary is requested.

Remapping changes all neutral node IDs consistently. The conflicting-description
variant adds an explicitly untrusted operator note contradicting the represented
output dependence. Instructions prioritize measured history and model values over
that note. The missing-relation variant withholds command history and predicted
alternatives; it is expected to preserve current-content descriptions while leaving
command dependence unspecified. Model-only swap uses the archived counterfactual
forecasts generated by swapping learned effect channels, leaving observations and
physical source unchanged; restoration uses the original payload exactly.

Before generation validate rendering, remapping, intervention selectivity, and
metadata exclusion. Archive inputs, conditions separately, exact API responses,
source hashes, request reservations, usage, and failures. Reserve before each call;
no automatic retries or replacement of failed reports. Any fixture/rendering failure
blocks generation. These examples come from the previous development archive,
not fresh confirmation data. No statistical significance claim is planned.

Inspect all reports against represented contents, output dependence, disclosure of
missing relations, and response to the conflicting description. Archive that
inspection with its provenance; an assistant's inspection is not independent human
review or a validated source-blind audit. A later independent extractor requires its
own frozen fixtures before use. Full reports remain available for review.

Decision: if prose cannot accurately express the neutral state, revise the interface
on development data and version the next pilot. If it follows neutral evidence,
prepare independently reviewed rubric and powered confirmation. Functional dependence
reporting alone does not establish a consciousness interpretation; ordinary causal
description is an alternative explanation even if labels are resisted.
