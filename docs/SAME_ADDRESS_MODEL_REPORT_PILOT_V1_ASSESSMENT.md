# Same-address pilot: prospective development measurement

The [finite assessment package](../audits/attention_relational_report_v1/same_address_pilot_v1/protocol/README.md)
prepares the [published pilot](SAME_ADDRESS_MODEL_REPORT_PILOT_V1_PLAN.md) without
reports, ratings or source inference. It binds one neutral short-report prompt,
whole-prose factual review and unchanged source-blind relational semantics in
two independent first streams each, all 72 positions and84 matched pairs.

Exact actor configuration, source payload/input hashes, ordering, transport and
retention paths must be bound before runs. Source-binding annotation is exposed
coordinator work after all first contexts end; it cannot overwrite firsts, fill
missing measurements or upgrade a conservative primary outcome. All availability,
fidelity, semantic and source-join results retain their planned denominators and
unknowns. This is development measurement, not proof of general auditor reliability
or a new qualification gate. The published plan's stop-or-advance decision applies.
