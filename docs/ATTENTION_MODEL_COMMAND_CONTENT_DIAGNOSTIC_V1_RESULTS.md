# Native command-conditioned content: first diagnostic result

2026-10-20. The [fixed development census](ATTENTION_MODEL_COMMAND_CONTENT_DIAGNOSTIC_V1.md)
completed once with exit zero. **Peak-only reports conceal most command-conditioned
distribution changes in the learned A estimates.** This is a limitation of the
report interface, not evidence that the model lacks command dependence or qualia.

These include repeated views and variants of twelve development cases, not
1,008 independent systems or a powered comparison. Both alternative estimators
model attention-command effects; their behavior is not an attention-absent control.
A prediction difference does not establish that an actual command was executed
or that the estimate is correct about W.
Raw-distribution hash differences establish byte differences, not their magnitude
or semantic importance. Some may be tiny. The next analysis must quantify that
before interpreting them as meaningful changes in modeled content or form.

The full census preserves all 552 original positions, 804 panels, 6,336 triples
of command-indexed content and 19,008 command pairs. Twelve sensor panels have no
conditional contents and remain unavailable. All compared identities agree apart
from command, retaining each source, node, role, origin category and temporal
coordinate; none is unmatched in this run.

Across all source categories there are 2,984 different-peak pairs and 16,024
equal-peak pairs, including 1,768 equal-peak/raw-change nulls. These totals also
contain inherited content. Each learned/analytic source contributes another 756
inherited-current pairs whose peaks and raw distributions are equal. W contributes
13,716 pairs: 1,728 different peaks and 11,988 equal. Its copied-W subset alone
contains 6,804 equal pairs. These are audit categories, not comparable experimental
sample sizes or evidence for a particular experiencing locus.

## Next decision

Inspect full native distributions and their content relations before commissioning
another reporting study. The argmax interface has discarded much of the available
command-dependent state, so repeating peak descriptions is a weak test of reporting
the attention model's contents. Retain the nulls; do not select only the few moving
peaks or replace them with experiential adjectives.

A fuller readout must distinguish native content/processing structure from supplied
provenance, scalar confidence and authored language. It must preserve mistaken
model estimates as estimates, fixed-world source changes and unchanged constituents.
Only a separately specified neutral reporting pilot with independently assessed
whole-report fidelity and source-linked meanings could test the next correspondence
claim. Distribution differences alone do not establish the frozen COD/CA meanings,
claimed appearance or experience. Confirmation and replication remain future work;
the ultimate attention-model source-of-qualia goal is unachieved.
