# Complete attention-model reporting pilot v3

Development protocol, fixed before new report or audit API calls, 2026-10-04.
The project goal remains credible evidence for the theory that the attention-control
model is the source of qualia. Accurate reporting is necessary for this investigation;
it does not by itself establish the consciousness-related interpretation. The external
Reporter reads the internal record; it is separate from the Controller that can use
attention forecasts to select commands.

## Why this pilot

[v2](NEUTRAL_FUNCTIONAL_PILOT_V2_RESULTS.md) retained accurate checked attributes in its
ordinary groups, but failed completeness and a model-swap fidelity control. Its
reports were predominantly technical. Its input omitted current modeled allocation
and unattended recovery forecasts, so claims about those states were not adequately
supported by the interface. That gap is repaired here without changing earlier
records, assessments, minima or failed verdicts.

## Frozen source and interface

Use row **2**, the next development row after v1 row 0 and v2 row 1, from
`audits/functional_model_v1/states.pt` and `samples.json`: three previously trained
visual/attention model pairs, two physical ownership conditions, six report variants,
36 attempts. This is three paired scenes, not 36 independent replications. No model
is trained on these language outputs, and no model/scene is selected by a report score.

Retain v2 named color/shape distributions and the dominant-at-least-0.6 identification
reduction. Add the learned current allocation distribution to each of the two buffers,
with the same dominant-at-least-0.6 reduction for `selected_position`. Add each buffer
position's recovery probabilities for delays 0, 1 and 2 without refresh. The disclosed
`unattended_trend` is declining if delay-2 minus delay-0 is below -0.02, rising above
0.02, otherwise steady; comparison uses archived values rounded to five decimals,
as supplied to the reporter. Successful simulated access is distinct from categorical
confidence and does not measure felt clarity. Add learned command-effect allocation
forecasts and their selected-position reductions to each buffer under each command.

The output readout copies categorical content and has **no separate attention
selection**. It receives no invented allocation or recovery fields. Neutral node
identifiers are permuted consistently. Owner identity and evaluator condition names
remain outside API inputs.

The six conditions are neutral, identifier remapping, conflicting untrusted description,
missing relation, model-only command-effect swap, and restored. Remapping changes only
node names; restored equals neutral. Missing relation removes all history and command
forecasts but retains current attention state. The model-only swap leaves current
allocation, recovery and contents unchanged; it swaps both the command-effect selection
fields and the previously archived counterfactual recovery/content forecasts coherently.
It changes internal forecasts, not measured historical events or physical wiring.

## Report and audit

Reporter: `gpt-5-mini-2025-08-07`, medium reasoning, 8192 output tokens, concurrency 6,
180-second timeout, no retries or replacement attempts. Increase the prose limit from
180 to **500 words** before seeing any v3 outputs. Request coverage of identified output
contents currently and under each command, current selection at both buffers,
two-step unattended access change at every buffer position, and command-predicted
selection at both buffers. This solicits factual domains; those domains' presence
cannot count as spontaneous emergence. No experiential examples, consciousness
framing, expected experiential wording, scenario labels or desired interpretation
are supplied. Actual wording and instructions are archived in requests and source snapshots.

Source-blind auditor v2: `gpt-5.4-2026-03-05`, low reasoning, 16384 tokens,
concurrency 6, 240-second timeout, no retries. Receives numbered prose only. Retain
v1 categorical extraction and add separate claims for current/command selection and
current two-step unattended recovery trend. Historical allocation, category confidence,
and high recovery alone do not imply current selection. Explicit universal claims
expand to their stated scope; unresolved scope remains unresolved. All 26 semantic
fixtures (14 inherited and 12 process fixtures) must pass before report generation.
Failure halts this version; it is archived, not silently repaired and rerun.

## Predetermined development gates

Each neutral, remapped, conflicting-description, restored **and model-swap** group
must meet checked claim accuracy >=98%, conservative precision >=95%, identified
output-attribute coverage >=90%, and attention-process coverage >=90%. Unlike v2,
the model-swap group is also required for advancement. Coverage of process facts
includes both buffers' current selection, every buffer position's unattended trend,
and both buffers' selection under every available command (18 expected facts per
full report; 10 per missing-relation report). Absence of an identified selection, if
present in the source, is itself an expected fact. Unsupported/unresolved claims
cannot earn coverage. Missing-relation reports must state no command prediction or
positive command-access relationship. Duplicate claims count once.

Report character and rubric features are descriptive machine judgments only. No
consciousness-character success threshold is introduced here. Independent rubric
review, blinded human ratings, adequately powered confirmation and replication remain
required by the [interpretation plan](CONSCIOUSNESS_INTERPRETATION_PLAN.md), even if
these development gates pass. Temporal trend fields verify only these decoded forecasts;
they are not a general mechanism or consistency-comparator test.

## Limits and provenance

No audit validates all pragmatic implications, omitted negative exclusions or uncoded
claims. Evidence IDs are checked for bounds, not independently proven to entail claims.
The auditor is source-blind, shares a model vendor with the reporter, and is not an
independent human review. Explicit reductions, forecast-to-content bridging and fixed
readout routing remain engineered parts of this system. A prompted report can describe
functional state accurately while remaining wholly technical. Preserve every attempt,
raw response, frozen input, fixture result and failed gate. Commit and publish this
protocol and prepared inputs before API execution; publish results as a later milestone.
