Separate subagent discovery now identifies attention-manipulated appearance studies beyond the existing contrast-only visibility/confidence candidate. **No candidate trial archive is qualified:** zero participant rows, stimulus files or native task code were acquired. The [full candidate ledger](../audits/attention_appearance_reference_v1/review.md) and [provenance/access record](../audits/attention_appearance_reference_v1/metadata.json) preserve exact sources, retrieval outcomes, corrections and limitations. No model output was used to select the candidate ledger, and no numerical human/model correspondence was computed. The positive, null, criterion-change and sign-reversal alternatives remain open. A cue-dependent response shift alone does not distinguish altered appearance from decision bias. An attention cue also does not directly measure the participant's internal attention model.

Before an executable external endpoint is frozen, qualify immutable trial/stimulus bytes, licenses, fields, exclusions, original analysis and corrections. Prioritize both a contrast-dependent appearance candidate and a decision/uncertainty control without selecting according to current model fit. Do not replace missing trial rows with aggregate plot values, invent appearance ratings or assign participants a latent attention-model state.

The [isolated task failure](ISOLATED_ORIENTATION_TASK_V1_RESULTS.md) remains a separate prerequisite. New task development must span intended sensory conditions and qualify conditional correctness calibration before grounding acquisition in outcomes. That engineering bridge must receive no human appearance targets. Subsequently compare sensory, attention-control-model, Controller and Reporter sources under matched information/development budgets, with selective model-state interventions and restoration in addition to whole-system attention manipulations. Qualified behavioral correspondence would constrain the theory's proposed function; its consciousness-related interpretation still needs an explicit inferential bridge.
