# Named neutral functional pilot v2: results

2026-10-04. **Development feasibility gates fail.** Named distributions eliminate
checked attribute errors in the four primary presentation groups, but output
coverage remains below the frozen minimum in three groups. A model-intervention
report overgeneralizes its command forecasts to a second buffer. These outcomes
are retained; no acceptance rule has been relaxed.

## Scope and audit

All 36 reporter responses and all 36 source-blind audits completed without retries.
The new auditor passed all 14 synthetic semantic fixtures before real extraction.
There are three underlying paired development scenes and six source states, each
with six variants, not 36 independent episodes or a confirmation replication.

The reporter reads named color/shape probabilities and transparent dominant-
attribute reductions. These factual reductions are engineered readout aids, not
consciousness labels. The auditor receives only numbered prose, not state,
condition, expected answers, or condition-bearing IDs. It uses a different model
from the same vendor and is not independent human validation.

Frozen primary minima are 98% checked accuracy, 95% conservative precision, and
90% output coverage. Only restored meets all primary factual minima. All six
missing-relation reports withhold command-identity claims and positive command-
effect relations, passing that control gate. The model-swap group is scored against
its altered internal forecasts, not unchanged physical truth.

Fourteen scored errors all come from `1301_r1_c1_model_swap`. Its explicit output
identifications are accurate, but it ends: “Corresponding forecasted changes appear
in the buffers (n1, n2) in the same way.” The audit expands this as matching
identification patterns in both buffers; n2 does not have those patterns. This
broad wording creates a conservative scoring failure. The report and extracted
evidence remain available to assess that interpretation. It is not silently
reclassified as an audit error or discarded from precision.

Coverage counts current and each command-conditioned identified attribute at the
output, including retained identities. A report can describe a command's new
identification accurately while omitting its retained identifications. Accuracy
and coverage must therefore remain separate. Quantified and implied statements
can also be missed by the extractor; no claim is made that all language implications
have been checked.

## Report character and architectural gap

Automated character labels are 30 technical and six mixed across all variants;
none is classified experiential. These descriptive counts are rubric-dependent,
correlated, and not independently human-rated. No consciousness-related positive
interpretation is established by improved attribute accuracy.

The present neutral record exposes categorical content, observed acquisition history,
and command-conditioned content forecasts. It omits the attention predictor's
current allocation and its one/two-step unattended recovery forecasts. The proposed
rubric includes focal/background distinctions and changing availability; those
model fields must be supplied before the main reporting question can be adequately
tested. Historical allocation alone is insufficient to establish current focus.

The next development version should restore those attention-model fields using
neutral node IDs, explicitly distinguish modeled recovery from identity confidence,
increase prose space where necessary for complete reporting, and avoid broad
unsupported buffer generalizations. It must retain all current values and reports,
freeze new inputs/audit fixtures, and use another predetermined development row.
This is a required information correction, not an instruction to produce a desired
phenomenological style. The external reporter remains separate from the Controller.

Independent rubric review and blind human ratings have been requested but not
received. The planned theory-facing confirmation remains unexecuted.
