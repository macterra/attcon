# Same-address reporting pilot: closed after assessment failure

2026-10-31. **The frozen pilot is complete and this reporting route is closed
for the current source/interface.** It does not advance to fresh confirmation.
The decisive reason is operational assessment failure: neither semantic stream
produced a valid annotation. This is an unmeasured endpoint, not a finding that
organization/access structure is absent, that the system lacks consciousness,
or that the qualia-source theory is false.

The [registered stop-or-advance rule](SAME_ADDRESS_MODEL_REPORT_PILOT_V1_PLAN.md)
closes this route on assessment failure. No replacement report, repaired first
annotation, alternate seed, prompt, reviewer or auditor was run. No further
reporting cycle is released by this result.

before review launch. All 48 planned review contexts are accounted for: 36 were

## Why the semantic endpoint is unknown

All 18 attempted semantic contexts failed while invoking the unavailable `python`
command. Fifteen saved no artifact; three saved error envelopes rather than
annotations. The frozen collector rejects those envelopes. S1 therefore has
66 missing-artifact positions (including 18 skipped) and six invalid-artifact
positions; S2 has 60 missing (including 18 skipped) and twelve invalid.

This was an avoidable execution-environment failure in the run coordinated here.
It is not a negative judgment about report meaning. No first semantic annotation
can be recovered from an error envelope, and the no-replacement rule prevents
turning a rerun into the original first measurement. The coordinator has not
substituted its own semantic ratings.

For COD and CA separately, the established joint yield is **0/72 with 72/72
unknown**, not 72 negatives. The observed possible count is zero because there
are no valid observations; the missingness uncertainty bound is 0–72. The same
accounting is retained for A 20, ordinary 20, analytic 20 and W 12. Scope and
current/future attribution remain unmeasured. There are no valid proposed
composite bindings to join to factual operands, including in the 35 reports
supported by both factual streams.

All 84 pairs retain both endpoint records, factual inventories, exact numerical
changes, source identities and clusters. The 28 baseline-to-restored pairs have
exactly equal public input contents. The other 56 pairs have input changes;
field-level nulls remain visible separately from origin metadata. **No pair
establishes semantic tracking or restoration**, because semantic assertions
are unmeasured. Input equality does not require identical sampled prose.

and complete child tool transcripts are not exposed to root. Canonical actor

even a positive result would have been development evidence rather than fresh
confirmation. The optional distinct architecture study in the registered plan
remains separate and has not been started.
