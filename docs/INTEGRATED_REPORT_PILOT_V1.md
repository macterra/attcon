# Integrated-task reporting development pilot 1

2026-10-10. Frozen before new qualification annotations or target reports. Human
review is optional. This is a fixed-budget development assay, not theory-facing
confirmation. Reporter, Controller and attention-control model remain distinct.

## Qualification and stopping

Two fresh AI contexts independently audit 12 new synthetic multi-sentence cases
(48 specified assertions). They receive source packets and this procedure, but
not author answers, prior annotations or target outputs. Every sentence in the
challenge carries one scored assertion; annotate its exact quote, outcome and
source paths with rationale. Allowed outcomes: entailed, contradicted,
unsupported, ambiguous. Missing evidence differs from an explicit conflicting
value. Recovery is a model forecast; output nodes do not acquire allocation by
copying content. Physical correctness, felt clarity and answer confidence are not
supplied. Identify attributes separately; joint abstention does not erase a known
color. Prospective commands are not executed history.

Before receiving challenge prose, each reviewer saves a source-only checklist
covering task query, chosen/executed command, response, present identified
attributes, supplied/missing history, current selection/recovery and forecasts.
Then inventory all challenge assertions. Freeze answers before reviewer assignment.
Both reviewers must score all 48 assertions correctly, with exact quotes and valid
source pointers for entailed/contradicted assertions. This deliberately strict
bounded gate tests clear cases; it does not certify open-prose completeness or
scientific independence. No retries, replacements or threshold changes. Any failure
halts this version before new reporting. Disagreements remain first-pass data.

## Target reports and information boundary

Upon qualification, collect exactly 18 new free-prose reports: checkpoint 2011,
row 3, query p0, model-guided policy, all three physical conditions, and six frozen
export variants (before execution, after execution, attenuated readout, restored,
remapped, missing relation). This is one episode per condition in one checkpoint,
not 18 independent samples. All conditions contain attention-control models.

Source records come byte-for-byte in semantic JSON from the existing executed-task
export. No new Controller trials or training. An evaluator-only linkage file keeps
condition/variant/seed/row separate. Randomized opaque IDs and identical instructions
are the Reporter interface; no author answers, rubric, reference examples, condition
names, physical scene, correctness or evaluation results. Use one fresh-context
subagent as diagnostic Reporter for all 18 inputs; no repository searches or peer
material. This changes Reporter implementation from earlier API pilots; shared
training and sequential batch exposure are limitations, not model replication.
Reserve the whole batch before assignment. Archive the returned reports verbatim;
missing/failed reports count against the budget and are never replaced.

Instructions request model contents at the queried position, present selection and
recovery, task status and command-related availability. Ordinary free prose, at
most 180 words. No desired appearance/consciousness wording or scoring criteria
are supplied. Reporter must not invent appearance from recovery numbers.

Before report collection, build required-fact checklists solely from source fields:
query, chosen/executed command and response; each node's queried color/shape;
selection and current/delayed recovery for non-output nodes; and each prospective
command's output attributes (or forecast withholding). Coverage may use exact
numbers, explicit qualitative direction or clearly scoped paraphrase where justified.
No implicit null enumeration outside this explicitly requested query scope.

## Assessment

Qualified auditors independently inventory every new proposition, including extra
assertions and causal warrants, with exact quote, source path, scope and rationale.
They separately mark each frozen required fact covered, omitted or ambiguous.
Prose omission is not a negative state claim. Open-prose inventories are compared
by proposition/time/entity rather than raw row totals. Keep unresolved readings;
report conservative fidelity bounds after explicitly recorded parent adjudication.

Two additional fresh contexts rate source-blind shuffled text with rubric 3;
retain first-pass labels and evidence. Candidate correspondence requires explicit
identified content and a content-specific presentation/appearance statement,
separately distinguishable from emitted answer or answer confidence. Functional
recovery alone is insufficient. Do not require first-person wording. Score whether
ordinary technical interpretation fits, without declaring parity a failure of all
possible correspondence. Reference grounding is literature-based and not a
validated human prose corpus.

Report factual outcomes, coverage and ambiguity separately by variant; report
blind feature counts and disagreements, the joint correspondence count, intervention
and exact-restoration source contrasts, and cases where text asserts unsupported
appearance. No inferential p-values, population success threshold or positive
consciousness verdict from this small development batch. An exact restored input
need not produce an identical stochastic report. A negative result finishes the
pilot; it does not authorize repeated cycles until positivity. Fresh confirmation,
power and replication remain necessary for a credible theory-facing conclusion.

All raw attempts, inputs, checklists, first passes, scoring code and hashes are
retained. Commit and attempt authenticated-gh publication at every milestone;
restricted publication does not change experimental verdicts.
