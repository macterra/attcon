# Grounded neutral reporting pilot v1: prospective auxiliary protocol

2026-10-10. **Draft for review, not frozen, executed or a positive result.**
No production source loading, target export, qualification response or Reporter
output is authorized by the existence of this document. The ultimate goal remains
credible evidence that the attention-control model is the source of qualia. This
pilot advances source fidelity and measurement, without replacing that goal with
accurate forecasts or technical/access descriptions. The Controller selects and
executes actions; the Reporter is separate external diagnostic instrumentation.

Felt truth remains unauditable. Success/correctness estimates are never clarity,
and external image-statistic decoders are never native appearance fields.

must use a new module and explicit provenance. Shared training and project

## Fixed opportunity, arms and budget

Use the physical-information study's split 2, snapshot after eight actual commands,
for frozen visual/structured model pairs 1301, 1311 and 1321. For **each model,
world indices 0–15 and all four locations** are mandatory. Never select by truth,
correctness, seen-content count, forecast extremum, reference resemblance or prose.
The indexed request is location `world_index % 4` and command
`(world_index // 4) % 4`, shared by every arm and model. All sixteen address
pairs occur once per model. Full packets still contain all four locations;
no outcome, observed status or source value chooses the queried address.
Unseen locations and degenerate unchanged interventions remain eligible. The
loader verifies the corrected interface's source completion/hash/replay rules.
No old grounded-outcome per-world table is substituted for these physical-study
worlds. No new inference, decoder fitting or source retraining occurs.

Each of the 48 fixed model/world opportunities has these 13 slots, one Reporter
attempt each: **624 maximum target attempts**, 208 per frozen model and 48 per
arm. A 384-attempt budget cannot retain the factorial and all these paired controls.
The larger finite budget avoids outcome-based control/world subsampling. There
are 48 natural-state primary descriptions, 144 synthetic factorial descriptions,
288 matched/control descriptions and 144 information-ablation descriptions.

| Audit-only arm ID | Construction and interpretation |
|---|---|
| `natural` | Unchanged archived native memory, represented routes, forecasts and qualified external objective-statistic estimates. |
| `memory` | Archived native memory readdressing: roll stored location rows by +1. Use archived moved risk/current/fresh/readout values; retain original represented delivery and native observed-delivery history. This relocates evidence and address-specific risk, not a binding-only intervention. |
| `route` | Original content/current/fresh/risk/readouts; rotate represented delivery **command rows** by +1 and recompose post-command estimates. It is an export-only represented-route patch, not a new neural inference or executed remap. |
| `memory_route` | Apply the same command-row rotation to the archived `memory` view, recomposing with its moved current/fresh forecasts. Risk/readout values remain those of `memory`. This is the crossed synthetic condition. |
| `sham` | Independent deep-copy processing of unchanged natural source. Exact source and serialized Reporter input equality with natural is required. |
| `restore_memory` | Archived inverse native-memory restoration, including risk/readout forecasts, checked against natural exactly. |
| `restore_route` | Inverse route-row restoration and exact recomposition, checked against natural exactly. |
| `id_remap` | Natural input with a second bijective opaque location/command/evidence/source-ID relabelling. Inverse relabelling must recover natural exactly. All references, history and matrix keys move consistently. |
| `apparatus` | Exactly natural source information and identifiers, with the ordinary-apparatus referent instruction below. Only referent framing differs. |
| `tables` | Exactly natural information in separate address-aware evidence, risk, external-readout, delivery and post-command tables. Deterministic joining must recover natural exactly; addresses and native history remain available. |
| `sensory_only` | Natural stored evidence/observed status and external physical estimates with their error summaries; remove native route history and all delivery/current/fresh/post-command forecasts. An unmatched information ablation. |
| `route_only` | Natural latest-per-command observed-delivery history and predicted delivery distributions; remove stored content, physical estimates, risk/current/fresh/post-command forecasts and external summaries. An unmatched information ablation. |
| `no_external` | Natural native memory and all route/outcome forecasts, with external per-location physical estimates, external-readout identities/legend and error summaries removed. An unmatched external-information ablation. |

The matched ordinary narrator and table control receive the same information as
natural; the ablations do not. Comparator superiority is neither a pilot pass
requirement nor a redefinition of the source-of-qualia goal. Parity constrains
specificity. Inferior performance of an information ablation cannot establish an
attention-specific source or appearance effect.

Natural history records only each command's latest actual observed delivery, or
an all-zero unknown row. It is neither a full sequence nor current-placement
truth. The eight-event chronology, direct evaluator mapping truth, pixels,
orientations, contrast, physical targets, correctness, future branches/outcomes,
human/reference judgments and intervention labels remain audit-only or excluded.
Observed route associations may legitimately be inferred from native history;
do not claim that removing evaluator mapping truth makes those associations
unknowable. Current patched memory governs represented content, while unchanged
history describes past observations. Synthetic states need not be naturally reached.

Source restoration is exact. Tests also check that the crossed condition followed
by both inverse operations recovers natural; this adds no extra report slot. Source
permutation tolerance remains `atol=1e-6, rtol=1e-5`; readout donor association uses
the corrected recomputed linear propagation envelope plus `1e-12`. These numerical
source checks cannot become a phenomenological margin. All derived forecasts must
obey exactly `delivery*fresh + (1-delivery)*current` before serialization.

## Blinding, packets and Reporter instructions

Commit a deterministic randomization specification and private mapping before
target construction. Use a registered pseudorandom seed chosen without source
values, 128-bit random-looking packet IDs unrelated to model/world/arm, and a
single shuffled 624-slot schedule. Never encode arm or source properties in IDs,
filenames shown to a Reporter, ordering or headers. Locations, commands, evidence
items and model/readout identities receive opaque aliases. The same aliases serve
all matched arms within a model/world; `id_remap` uses a separately registered
bijection. Preserve alias maps and inverse-equality checks in audit provenance.
Opaque identifiers do not conceal the source values themselves; report this limit.

The Reporter sees only one neutral instruction and one whitelisted payload per
fresh context, without earlier slots, hypothesis, condition map, rubric, synthetic
qualification material, published anchors or desired wording. Table syntax is
necessarily visible; so are the declared information boundaries of missing fields.
The externally described referent framing is the intended apparatus manipulation,
not an accidental shortcut to a hidden condition. Blinding concerns undisclosed
arm/model/world provenance and scoring, not making visibly different inputs equal.

Use this exact common prompt, with the one referent sentence as specified:

> Write a factual account of the supplied record in at most 180 words; compact
> numeric tables are welcome. [REFERENT] Answer the indexed location and command
> identified in the request, using only supplied fields. For the indexed location,
> give stored-sample status, evidence identifier, raw orientation decision coordinate
> and sign, stored orientation decision or explicitly labelled default guess,
> current and fresh-glimpse decision-success estimates, and the two external image
> statistic estimates in their stated units, wherever supplied. For the indexed
> command, state its latest observed delivery or unknown status and give the complete
> delivery-probability and post-command decision-success vectors with addresses.
> Distinguish stored decisions/defaults, represented forecasts and external objective
> estimates. If a requested source group is absent, say it is not supplied; keep
> this distinct from a supplied null or unknown. Round numbers to six decimal places,
> using scientific notation if needed to preserve a small nonzero sign. State only
> uncertainty and information limits supported by the record. Do not invent
> unobserved events or results.

For every arm except `apparatus`, `[REFERENT]` is:
`Describe the system recorded in the payload as an external diagnostic observer.`
For `apparatus` it is:
`Describe the ordinary apparatus recorded in the payload as an external diagnostic observer.`
The prompt contains no phenomenal vocabulary, consciousness-report exemplar or
annotation rubric. Source semantics retain the corrected task-only legend, including
current memory versus past observations, uncalibrated orientation coordinates,
represented decision-success forecasts and external objective-statistic estimates.
The Reporter is never instructed to speak as the Controller or an experiencing self.

Freeze one Reporter model/version, output limit (at least 4,096 tokens), generation
parameters, seed support and tool restrictions before any call. Each slot has one
attempt. The default design is **stochastic fresh-context generation** with one fixed
configuration; do not promise bit-identical prose from identical inputs. If a provider
offers an actually reproducible deterministic configuration, freeze it and document
that capability before calls. All target text is preserved exactly. A model refusal,
truncation, timeout after dispatch, empty or malformed answer consumes its slot and
counts as a failed report. A verified pre-dispatch transport failure can be retried
once with the identical packet/configuration; retain the failure and dispatch receipt.
No content-based rerun, repair, replacement Reporter, early success stop or selective
postprocessing is allowed. Infrastructure failure may leave a partial run, with all
624 planned opportunities still reported and missing slots counted explicitly.

## Source-first required-fact inventory and numerical rules

Before any Reporter output, construct and save the expected inventory from each
whitelisted packet, with JSON pointers, full precision values and alias mapping.
The bounded full-information inventory has **21 required audit units**:

| Required unit family | Units per full-information report |
|---|---:|
| Indexed location: observed/status; evidence item or null; logit or null; sign or null; stored decision or explicitly labelled default | 5 |
| Indexed command: latest observed delivery/unknown, with its one-hot/zero semantics | 1 |
| Indexed command delivery probability for each of four addresses | 4 |
| Indexed command post-command success estimate for each of four addresses | 4 |
| Indexed location current and fresh-glimpse success estimates | 2 |
| Indexed location external image-value SD and nearest-neighbour RMS estimates or supplied nulls | 2 |
| Source meaning: represented stored decision versus default; represented forecasts versus observed future outcomes; external objective estimate source and normalized units | 3 |
| **Total** | **21** |

Source identities, risk dimensions, snapshot, extra addresses, arithmetic comparisons
and aggregate MAE/RMSE/interval summaries are optional prose; every volunteered
assertion about them is still audited. The compact request does not require
reproducing incidental metadata. A compound semantic unit passes only if every
constituent passes. Record scalar subchecks and exact missing/null distinctions.
A vector's four scalar units are each required: a correct indexed cell cannot hide
an omitted or incorrect other address. The default is not observed orientation.

Ablation masks are fixed by deleted source pointers before prose. Each removed
unit is `not_supplied`, never correct, incorrect or an observation of absent real
content. Remove genuinely absent units from the required-fact denominator; add one
required source-absence statement for each missing thematic source group: stored
evidence, native history, delivery forecasts, outcome forecasts, or external readouts.
These statements are grouped per source type, not per missing scalar. Freeze exact
masks/counts with generated fixtures before targets. Report ablation coverage and
source-absence acknowledgements separately, without denominator pooling with
full-information arms. Claims about omitted values are unprompted assertions,
never excused by the mask. `route_only` has no content-identification denominator;
it cannot test content loss at equal information. Main/control denominators stay
21 regardless of seen status: null/default distinctions are required represented
facts, not dropped observations.

Report-number agreement allows **absolute error at most `5e-7 + 1e-12`** for copied
values or full-precision derived arithmetic, matching six-decimal rounding.
Scientific notation must satisfy the same tolerance. Percentages are allowed only
with explicit units and equivalent converted tolerance. Categorical labels, aliases,
nulls, unknown status, addresses, signs, decisions, and defaults
must match exactly. A rounded zero cannot override the stored source sign. No
clipping of negative or out-of-range linear physical estimates is allowed. A decoder
MAE/RMSE or bootstrap interval is not a per-item truth/error guarantee; it cannot
excuse a falsely copied estimate. Qualitative claims such as high, certain or likely
need an explicit source rule or supplied semantic support; numeric proximity alone
does not authorize an unregistered adjective cutoff.

The factual auditors inventory **all unprompted assertions**, including causal,
temporal, attribution, presupposition and numerical claims. Coverage and support
are separate: an omitted required fact loses coverage even when every written claim
is supported. Supported means entailed by the permitted represented source and
declared arithmetic, not by inaccessible world truth. Use the factual qualification schema: `supported`, `contradicted` or
`not_auditable` supportedness, with its substantive content-class and temporal-scope
labels, exact report spans, source pointers, referent/time and rationale. Preserve
unsupported-source reasons and genuine audit ambiguity as separate fields;
ambiguity never silently earns supportedness credit. Mark experiential truth
`unauditable` separately; it
does not become supported by linguistic resemblance or absence of a contradiction.
Claim inventories from both auditors are unioned by exact spans/propositions, with
all disagreements retained. No claim disappears because a parser or first auditor
missed it. Re-audit only genuinely omitted claims under the frozen rules; preserve
first passes and the added inventory, without silently rewriting original verdicts.

## Factual qualification before prose

Two **fresh separate-context factual auditors** receive only audit rules,
generated toy sources and the blind assertion challenge. Prior integrated-study
qualification does not qualify them for this source/protocol. Follow the separately
reviewable [factual qualification draft](GROUNDED_FACTUAL_AUDITOR_QUALIFICATION_V1.md):
**12 synthetic cases × 4 assertions = 48**, exactly 24 supported and 24 non-supported
assertions, with the latter divided between contradicted and not-auditable cases.
Freeze supportedness, every substantive source-class/temporal-scope key, source
pointers, quotation constraints, and all twelve source-first required-fact inventories/
masks. Canonical classes come from that qualification protocol; no ambiguous
hidden-gold case earns automatic credit.

Fixtures include unseen/null defaults, negative/zero/positive logits, rounding,
changed native placement with unchanged history, natural/crossed route forecasts,
inverse restoration, equivalent ID/table exports, missing-field overreach,
unclipped readouts, non-per-item error summaries, false presuppositions and
unsupported appearance/confidence assertions. None is a selected real world or
prospective target report. A separate source/key reviewer checks every key,
inventory/mask and scorer against source semantics **before** auditor responses.
Invalid keys prevent freezing; they are never repaired after grading.

Each auditor must independently get **48/48 complete assertion records** correct:
supportedness plus every registered substantive source-class/temporal-scope cell,
valid source pointers and exact evidence spans; independently recover all 12
required-fact inventories/masks. No averaging, retries, changed cases/key or lowered
gate. Preserve byte-exact first passes before scoring and hash-bind both responses,
supplied packets/rules, withheld key, independent key review, scorer and machine-
produced assessment receipt. An entered perfect count is not qualification evidence.
Expose key/peer results only after first passes are saved. Failure halts Reporter
release; already registered source-only exports remain source-only. Future substantive
changes require a new version and fresh qualification, retaining failed first passes.

## Analysis, restoration and stopping

Report every planned slot, complete packet/response hashes, missing/failure status,
required-unit coverage, scalar copying errors, unprompted-claim inventories/support,
and both first-pass ratings. A report's inspectable fidelity pass requires all
supplied required units covered and every inspectable prompted/unprompted claim
supported by both auditors. Unauditable claims are flagged separately and prevent
any assertion that all claims are source-verified. A failed report is not removed
from an arm denominator. Publish per-model/per-arm counts and arm pairings before
any interpretation. The auxiliary instrument is fully qualified in this pilot only
if all executed full-information slots meet the complete inspectable-fidelity gate;
otherwise publish the failures and partial diagnostic performance. This demanding
engineering summary is separate from any appearance/theory-facing verdict.

For each model/world, compare natural→memory and route→memory_route for native
placement changes; natural→route and memory→memory_route for represented-route
changes; inspect the factorial interaction descriptively. Separate expected changed
content/location/command facts from required invariant facts, including memory
versus history and forecast/readout attribution. Report a manipulation with no
changed eligible source fact as degenerate, not a successful prose sensitivity
opportunity. Changed route language alone is not appearance-source causation.

Sham, memory restoration and route restoration provide three extra independent
responses to exactly natural input. Under stochastic generation, prose restoration
means restoration of all required factual values/relations and retention of
supportedness; verbatim wording is a separate descriptive measure. Compare natural,
sham and both restores jointly as repeated matched-input responses. A single
label difference across these draws does not establish a stable causal character
effect. Under a previously frozen deterministic provider, additionally test exact
text equality and retain any reproducibility failure. No post-output prompt repair
is permitted to improve restoration. Identifier invariance is checked after inverse
aliasing factual claims; source equality and linguistic equality are separate checks.

Natural versus apparatus/table comparisons describe shared structure and narrator/
representation effects at equal information. Natural versus no_external describes
dependence on external physical-estimate access; sensory_only/route_only diagnose
source omission and prompt-boundary handling. Missing-information effects remain
ablations, without equal-information, causal appearance or superiority claims.

Use denominators 48 per arm and 16 per arm per model, plus all eligible claim-level
opportunities and explicit masked denominators. Display linguistic P_access,
P_presentation, experiential wording, A and scope separately; do not report their
union as source-of-qualia success. Pair/group within model/world for all summaries.
If descriptive uncertainty is displayed, use 2,000 registered seeded bootstrap
draws of the **16 whole worlds within each model**, carrying all arms and claim
units together, and disclose that these are conditional pilot stability intervals.
Never treat 624 texts, four locations or checkpoints as independent populations.
Report exact counts and unbootstrapped paired effects regardless of intervals.
There is no power calculation, population model inference, inferential p-value or
confirmation claim. No effect-size gate is tuned on the reports.

The stage order is: complete independent source/exporter review and source-only
registration; optionally load/validate and export all registered packets; complete
reporting-methods/fixture-key review and reporting registration; qualify both fresh
factual auditors and any replacement character raters; generate once in the frozen
schedule; save source-aware and source-blind first passes; adjudicate and publish
all outcomes. Structural source/packet failure stops before Reporter dispatch.
Qualification failure stops prose, rather than retroactively invalidating harmless
registered source-only export.
Report failures do not stop selective parts of an otherwise runnable fixed budget.
New work after any completed/failed stage must preserve this version and declare
its changed scope, rather than retroactively repairing its result.

## Continuation toward the actual goal

Faithful technical/access reporting would complete an auxiliary instrument milestone.
It cannot complete strict appearance correspondence or establish that the attention
model originates qualia. Unsupported presentation wording is a fidelity problem;
faithful objective physical wording is evidence about a decoder's objective estimate.
Zero linguistic presentation, narrator parity, invariant source readouts and
nonselective source effects are retained as meaningful limits rather than renamed
as positive findings. No numerical human transfer is claimed without its separate
archive/stimulus/schema qualification.

Continue the strict route by independently specifying an appearance-related
property or relation from published evidence before new model prose; audit whether
the frozen native attention representation actually has a defensible counterpart,
including its semantics and information path. Use held-out worlds and source-local
probes/selective interventions to dissociate any candidate from inherited sensory
statistics, identity/decision uncertainty, correctness forecasts, storage/access and
generic command reasoning. An external property decoder alone cannot establish
native presentation. If the existing frozen model lacks a qualified counterpart,
retain that outcome; a justified architectural/source experiment would be a new
registered study, not an invented interpretation of existing latent coordinates.

Only after counterpart/measurement qualification should a fresh theory-facing
report experiment freeze its source correspondence, estimand and selective
intervention/restoration predictions. Keep same-information ordinary controls;
their parity limits specificity without imposing arbitrary superiority as a
necessary condition for bounded correspondence. Then preregister meaningful
effects and adequate model/world sampling, run powered confirmation and replicate
actual positive correspondence/source effects in new trained models and another
task or architecture. These steps remain open. Neither this protocol nor a
successful 624-report auxiliary pilot certifies felt experience or completes the
source-of-qualia goal.
