# Grounded neutral-report pilot v1: source export results

2026-10-10. The registered source-only stage exports **624 packets**, covering
13 arms and 48 model/world opportunities. Exact source replay and an independent
JSON review pass. No new Reporter output, learned-model inference or decoder fit
was performed. This establishes the inputs for a reporting experiment, not report
accuracy, consciousness-report correspondence or the source of qualia.

## Registration and execution

The [pilot design](GROUNDED_NEUTRAL_REPORT_PILOT_V1.md) separates source export
from reporting authorization. The [source-only registration](../audits/grounded_neutral_report_pilot_v1/registration.json)
was committed at `9cb69dfd86f5a654bddd822fe9ddcec1b721b546` before selected
archive loading. It binds the reviewed exporter, interface, tests, design and
source-file hashes. The source export is saved at
`ec65d39537e1b2612c823b65497183464b120ab6` in the recovery checkout.

The sole registered export took 85.085 seconds. Each arm contains 48 packets:
16 worlds for each of three frozen models. The indexed queries cover all sixteen
location/command pairs per model. All four locations remain represented when
supplied. Opaque identifiers, the fixed shuffled schedule, intervention mappings,
source-first required facts and source hashes are saved separately from the
Reporter payloads. Full chronology and evaluator mappings remain audit-only.

The arms are natural, memory, route, memory_route, sham, restore_memory,
restore_route, id_remap, apparatus, tables, sensory_only, route_only and no_external.
The last three are unmatched source ablations. The memory intervention changes
native evidence placement together with its risk/readout associations; it is not
a pure binding manipulation holding attention marginals fixed. Route intervention
changes represented forecast rows and recomposes consequences; it is not a new
joint-network inference.

## Interpretation and continuation

The packets distinguish native stored decisions/defaults, attention-model
forecasts, latest-command history and external objective image-statistic estimates.
An unseen native sample is not a world-absence claim. Forecasts are not observed
future outcomes. External physical estimates are not experienced appearance.

The Controller acts on system information; the external Reporter describes it.
Neither is identified with the proposed experiencing locus by this export. Strict
source-faithful presentation remains `not_established`, felt truth is unauditable,
and the source-of-qualia goal remains open.

Fresh factual-auditor qualification and a separately reviewed reporting
registration, adapter, configuration and release verifier still precede target
prose. The frozen source exporter deliberately keeps Reporter release unavailable.
Successful auxiliary reporting would qualify an instrument. Theory-facing progress
still requires an independently defensible appearance counterpart, report
correspondence, selective source effects, powered confirmation and replication.
