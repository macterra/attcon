## Stage 1: construction provenance before reference outcomes

Build a read-only auxiliary index for all 552 literal texts. Independently
reconstruct the frozen template's header, every origin-JSON token and every
role/peak-set token from its actual packet. Require exact complete text equality
and exact required-proposition equality with the published template. Retain
Unicode-codepoint start/end offsets, text hashes, the packet path, full property
value, panel/view/command/node/role and actual declared origin/time. Verify every
character belongs to one token or its explicit separating space; no fuzzy matches,
first-occurrence selection or changed rendering. Index every tied peak, including
true nulls. Source identity comes from the actual provenance plus origin chain,
not the opaque panel name.

The index proves which source property generated text. It does not establish
which property made a reference feature apply. Retain global headings/coordinate
rules separately from source-content assertions. Copied W11, current A, conditional
A, inherited records, ordinary, analytic, native W and sensor remain distinct.
A_only is a hybrid; never attribute all its tokens to A. Preserve represented,
record, feedback and archived/counterfactual times without substituting fields.

Independently recompute every complete exact-maximal peak set from the actual
supplied distribution, under the documented float32 convention. Verify stored
derived peaks and template proposition cells against that independent result;
reusing the renderer and its stored derived peaks alone is circular. A fixture
must reject a jointly corrupted derived-peak field, proposition and rendered
template when the underlying distribution is unchanged. Check literal origin and
header claims separately rather than treating peak checks as whole-text proof.

Publish this index and its exact reconstruction checks before reference analysis.
Fixtures verify accounting, mixed origins, Unicode offsets, tied peaks and exact
restoration; they do not establish semantic correspondence.

## Stage 2: complete reference inventory and semantic attribution

After the full first V3 batch reaches its actual terminal state, collect and derive
it using its frozen contract. Retain all 1,104 reference opportunities, including
552 templates and 552 narrator texts, all missing/invalid responses and their
reasons. The separate template analysis has a fixed denominator of 552, across
all twelve archived cases. Do not infer feature absence from invalid or unavailable
annotations. Narrator factual fidelity remains unestablished by failed instruments.

For every valid template reference-evidence entry, list every intersecting or
containing construction token and all its source operands. Retain boundary-crossing,
header-only, partial-token, repeated and mixed evidence. This overlap inventory
is geometry, not a semantic source-attribution decision.

Two separate-context reviewers independently inspect every valid template evidence
entry, its complete report/annotation, exact candidate construction properties and
source provenance. Attribute the particular atomic property or nested origin field,
including its path and value, rather than an entire intersecting token. Generic
estimate labels and prefixes alone cannot establish A-content meaning. Review
whether the quotation actually grounds the claimed reference feature; retain
unsupported feature grounding separately from unresolved source attribution. They determine whether the evidence earning the feature
actually concerns each candidate property, retaining the rater's referent,
attribute, scope and time. Save all first mappings before peer inspection. Root
may resolve explicit disagreements against unchanged evidence; unresolved cases
remain unresolved. No mandatory human review. Shared model training remains a
limitation, and review is not a new system observation. Publish the complete
review packet and grading rule before reviewers see reference judgments.

Retain categories: established source-specific meaning; established mixed-source
meaning; global/template convention; unrelated property; unresolved. Exact
containment alone cannot earn an established semantic category. Record separately
whether correspondence concerns model organization, modeled access, claimed
appearance, physical content, uncertainty or purported subjective experience.
Model organization is not automatically perceptual appearance.

Report COD and CA separately using frozen composite bindings and all their
necessary compatible evidence. Do not build an endpoint from unrelated C/O/D/A
fragments. An actual A-dependent relational endpoint must involve an established
A-derived property or an explicit relation involving it; copied-W-only and generic
header evidence cannot establish it. Preserve partial, mixed and unresolved results
alongside unconditional 552-position yields; any valid-only proportion is secondary.
Neither template fidelity nor one attributed quote upgrades the endpoint's scope.

## Stage 3: the full 684 fixed causal pairs

Retain the original pair inventory, all source/view variants, shams and restoration
pairs, with per-case results. Align properties by source, address and property
identity, never character offsets or token positions. Construction failures remain
explicit unavailable measurements within the full inventory; they are neither
true invariance nor feature absence. Restored or repeated texts/pairs do not add
independent observations. Compare the actual indexed properties and independently
attributed endpoint evidence, rather than string changes or required category
switches. Donor-source changes should move the relevant source property at fixed
comparison W; fixed-A/W changes should preserve A assertions while allowing W
assertions to change. Preserve unaffected assertions, mixed operands and genuine
null peak-set changes even when the hidden distribution changed. Restore exact
baseline properties/text when the archived restoration does so.

A changed endpoint label is unnecessary: one structure can describe different
contents. An unchanged label or peak does not show ignored A. Record missing
endpoint measurement separately from actual invariance. Ordinary uses the same
architecture with another initialization; both ordinary and analytic alternatives
also estimate attention-command effects. Their parity neither supplies an
attention-model-absence contrast nor invalidates correspondence by definition.
Report source-model errors versus actual world state separately from faithful
reports of those estimates.

## Interpretation and next decision

A positive result would establish limited correspondence for authored diagnostic
text about identified model contents and show which functional properties support
it. Causal tracking of a literal renderer principally checks the measurement path;
it is not independent evidence of experience. A null, absent or unresolved result
must remain available and can falsify this proposed bridge under its stated scope.
Do not call model-organization/access correspondence a qualified appearance endpoint.

Use this finite analysis to decide whether a fresh neutral-reporter study is
justified and which properties require a better native counterpart. Free-prose
factual measurement must independently qualify before claiming its conjunction.
Fresh systems, a predeclared meaningful effect/precision, powered confirmation and
a new-task/architecture replication remain future requirements. No new auditor
version or repeated fiction challenge is commissioned by this plan. The ultimate
goal remains credible evidence for the attention-control-model source-of-qualia
theory, and is not achieved by construction provenance or this analysis.
