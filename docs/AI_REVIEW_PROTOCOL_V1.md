# AI review and factual-audit development, version 1

2026-10-10. Prepared before assigning the new reviewers. The user explicitly
authorized subagents instead of waiting for humans. This prospective development
review supersedes human-only prerequisites in the current plan. Historical frozen
protocols, scores, failed qualification and original review packets remain intact.
It is not a theory-facing confirmation protocol or evidence of experience.

Three fresh subagents receive separate tasks without parent conversation history.
D reviews rubric draft 2 and its definition form before viewing reports or other
reviews. A and B independently inventory and judge all 28 original synthetic cases
and the 12 unchanged v5 reports reserved for later whole-prose development checking.
Each sees the supplied state needed for factual judgment, but no author answer key,
experiment linkage, condition assignment, previous score or peer annotation.
They must preserve exact quotes, character spans, proposition scope, modality,
source pointers, ambiguity and extra assertions. Each records which reports were
completely inventoried and omissions or unresolved boundaries. An omitted requested
fact is not a false proposition. The input bytes/hashes are saved before review.

Reviewers are AI, commissioned by the same project, and may share model, training
and bias. Separate contexts give procedural independence, not independent human
validation, secure blinding or independent scientific replication. No human
approval is required to continue engineering, definitions or AI-rated experiments.
Optional human review may later provide additional evidence.

Archive each first pass before comparison. Compare proposition inventories as
well as outcome agreement; do not calculate agreement using only convenient matched
rows. Preserve missing/extra propositions, reasonable alternate readings and
adjudication separately. Author expectations can be consulted only after first
passes are archived, and must remain labelled expectations rather than unquestioned
gold. Parent synthesis must explain disagreements with source evidence.

This is an assessment of a proposed measurement procedure, not an automatically
passing qualification test. No threshold is fitted to these annotations, no prior
pilot is rescored into success, and formatting checks never certify semantics or
whole-prose completeness. New integrated-task reporting still needs task-vocabulary
cases, a source-matched coverage checklist and prospectively frozen acceptance
rules. The development reviews inform those rules; they are not confirmation.

Definition review must address what correspondence is consciousness-related and
what ordinary-description controls can establish. Attribution alone is not promoted
to a phenomenal endpoint. Reporter, Controller and the attention-control model
remain distinct. A conclusion that current features are nondiscriminating is a
valid review outcome, not a reason to replace reviewers until they endorse them.

Milestones retain local commits and attempt publication using authenticated `gh`.
Current network and protected original Git metadata may prevent publication; save
commits in the existing isolated checkout and durable bundle while that persists.
